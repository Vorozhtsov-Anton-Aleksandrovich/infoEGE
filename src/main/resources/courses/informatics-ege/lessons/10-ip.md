## 1. IP-адрес: почтовый адрес компьютера

Каждое устройство в сети имеет **IP-адрес** — как почтовый адрес у дома. Он записывается четырьмя числами через точку:

**192.168.37.200**

Каждое число — это **один байт**, то есть 8 бит, поэтому оно может быть от **0 до 255** (2⁸ = 256 вариантов). Весь адрес — 4 байта = **32 бита**.

Адрес состоит из двух частей, как почтовый адрес:

- **адрес сети** — «улица»: общий у всех компьютеров одной сети;
- **номер узла** — «дом»: свой у каждого компьютера в сети.

![IP-адрес как почтовый адрес: сеть — улица, узел — номер дома](images/ip-postal.svg)

Где кончается «улица» и начинается «дом», говорит **маска**.

:::try
Может ли существовать IP-адрес 10.256.0.1?
---
**Нет.** Каждое число — один байт, максимум 255. Число 256 в байт не помещается.
:::

## 2. Двоичная запись байта

Для задания 13 нужно быстро переводить числа от 0 до 255 в двоичную систему (8 бит) и обратно. Веса разрядов байта:

| 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|---|---|

Например, 200 = 128 + 64 + 8 → **11001000**. А 37 = 32 + 4 + 1 → **00100101**.

Числа, которые встречаются в масках, лучше выучить:

| Двоичная запись | Число | Единиц |
|---|---|---|
| 10000000 | 128 | 1 |
| 11000000 | 192 | 2 |
| 11100000 | 224 | 3 |
| 11110000 | 240 | 4 |
| 11111000 | 248 | 5 |
| 11111100 | 252 | 6 |
| 11111110 | 254 | 7 |
| 11111111 | 255 | 8 |

## 3. Маска

**Маска** — тоже 32 бита. В ней сначала идут **только единицы**, потом **только нули**. Единицы отмечают биты адреса сети, нули — биты номера узла.

![Адрес и маска друг под другом: граница сети и узла проходит там, где в маске кончаются единицы](images/ip-mask.svg)

- 255.255.255.0 → 11111111.11111111.11111111.00000000 — **24 единицы**, 8 нулей.
- 255.255.240.0 → 11111111.11111111.11110000.00000000 — **20 единиц**.

Маску часто записывают коротко — числом единиц через косую черту: **/24**, **/20**.

:::warn 255.255.255.0 — это 24 единицы
255 — это восемь единиц, а не одна! Число единиц в маске = 8 · (число байтов 255) + единицы в «неполном» байте.
:::

:::quiz
Какое из чисел **не может** быть байтом маски?
- [ ] 0
- [ ] 192
- [x] 160
- [ ] 252
---
160 = 10100000 — после единицы идёт ноль, а потом снова единица. В маске после нуля единиц быть не может.
:::

## 4. Адрес сети = IP & маска

**Адрес сети** получают поразрядной конъюнкцией (урок 5) адреса и маски: в каждом разряде 1 & 1 = 1, а всё остальное даёт 0. Иначе говоря, маска «оставляет» биты сети и «обнуляет» биты узла.

Считать нужно только «неполный» байт маски — остальные байты простые:

- байт & **255** = сам байт;
- байт & **0** = 0.

:::steps Разбор: IP 192.168.37.200, маска 255.255.240.0
1. Первые два байта маски — 255, они не меняют адрес: 192.168.
2. Четвёртый байт маски — 0: даёт 0.
3. Третий байт: 37 & 240. В двоичной: <span class="hl-blue">0010</span>0101 & <span class="hl-blue">1111</span>0000 = <span class="hl-blue">0010</span>0000 = 32.
4. Адрес сети: **192.168.32.0**.
:::

Попробуй сам: меняй адрес и маску (можно писать и /20):

:::widget ip-mask ip="192.168.37.200" mask="255.255.240.0"

## 5. Количество адресов в сети

Номер узла — это нулевые биты маски. Если нулей **k**, то различных номеров **2ᵏ**.

- Маска /24 → 8 нулей → 2⁸ = **256** адресов.
- Маска 255.255.240.0 = /20 → 12 нулей → 2¹² = **4096** адресов.

:::warn Минус 2, если спрашивают про компьютеры
Два адреса в каждой сети заняты: номер узла **из одних нулей** — это адрес самой сети, а **из одних единиц** — широковещательный адрес (сообщение «всем»). Поэтому:
- «сколько **адресов** в сети» → 2ᵏ;
- «сколько **компьютеров (узлов)** можно подключить» → 2ᵏ − 2.
:::

:::try
Сколько компьютеров можно подключить к сети с маской 255.255.255.192?
---
192 = 11000000: в последнем байте 6 нулей. Адресов 2⁶ = 64, компьютеров **64 − 2 = 62**.
:::

## 6. Найти байт маски по адресу сети

Обратная задача: «IP 111.81.208.27, адрес сети 111.81.192.0. Чему равен третий байт маски?»

:::steps Разбор
1. Выписываем третьи байты: IP — 208 = 11010000, сеть — 192 = 11000000.
2. Сравниваем разряды слева: там, где в IP 1, а в сети тоже 1 — в маске **обязательно 1** (1 & 1 = 1).
3. Там, где в IP 1, а в сети 0 — в маске **обязательно 0**. Это разряд 16: в 208 он равен 1, а в 192 — 0.
4. Маска — единицы, потом нули. Единицы должны быть в разрядах 128 и 64, а ноль — в разряде 16. Разряд 32 может быть любым: в IP там 0, результат всё равно 0.
5. Варианты: 11000000 = **192** и 11100000 = **224**. Наименьший — 192, наибольший — 224.
:::

## 7. Адреса с условием

Новый тип задания 13: «Сколько в сети адресов, у которых количество единиц в двоичной записи кратно 5?» Его проще всего решать программой — перебрать все адреса сети.

```python
from ipaddress import ip_network

net = ip_network('172.16.168.0/255.255.248.0')
count = 0
for ip in net:
    if bin(int(ip)).count('1') % 5 == 0:
        count += 1
print(count)
```

Модуль `ipaddress` сам перебирает все адреса сети, а `int(ip)` превращает адрес в 32-битное число.

## 8. Частые ошибки

:::warn Так нельзя
- Считать, что в 255 одна единица. В 255 — **восемь** единиц.
- Делать & с маской «в десятичной»: 37 & 240 ≠ 37 · 240 и ≠ min(37, 240). Только в двоичной, по разрядам.
- Забыть «− 2», когда спрашивают про узлы (компьютеры).
- Вычитать 2, когда спрашивают про **все** адреса сети.
- Писать байт маски, в котором после нуля снова идут единицы.
:::

## 9. Шпаргалка урока

:::cheat
- IP-адрес — 4 байта (32 бита), каждый от 0 до 255.
- Маска: сначала единицы (сеть), потом нули (узел). /24 = 255.255.255.0.
- Байты маски: 128, 192, 224, 240, 248, 252, 254, 255.
- **Адрес сети = IP & маска**; байт & 255 = байт, байт & 0 = 0.
- Адресов в сети: **2ᵏ**, где k — число нулей маски. Узлов: 2ᵏ − 2.
- Python: `from ipaddress import ip_network`, `for ip in ip_network('адрес/маска'):`.
:::
