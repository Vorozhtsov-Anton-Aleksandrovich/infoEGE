# Урок 5. Логика: отрезки и делимость (задание 15)

:::note Зачем это нужно
**Задание 15** ЕГЭ — «найдите наименьшее (наибольшее) A, при котором формула тождественно истинна». Бывает три вида: **отрезки** на числовой прямой, **делимость** ДЕЛ(x, A) и **поразрядная конъюнкция** x & A. Все три решаются одним методом, который мы разберём в этом уроке.
:::

## 1. Что значит «тождественно истинна»

Формула **тождественно истинна**, если она равна 1 **при любом** значении x. Достаточно одного x, при котором формула ложна, — и A не подходит.

Поэтому главный вопрос задания 15 всегда один: **при каких x формула может оказаться ложной?** Эти x нужно «закрыть» выбором A.

## 2. Отрезки на числовой прямой

Запись **x ∈ P** читается «x принадлежит отрезку P». Если P = [10; 40], то x ∈ P истинно для 10 ≤ x ≤ 40 и ложно для остальных x.

![Числовая прямая с отрезками P = [10; 40] и Q = [20; 60]](images/segments-pq.svg)

Так формула про отрезки превращается в обычную логическую формулу: x ∈ P, x ∈ Q, x ∈ A — это три логические переменные, значения которых зависят от того, где на прямой стоит x.

### Метод решения

1. Перепиши импликации через «ИЛИ»: A → B = ¬A ∨ B.
2. Найди, где формула **может быть ложной без A** — это «красная зона».
3. Подбери A так, чтобы он закрыл красную зону (если A стоит в формуле без отрицания) или **не залезал** в неё (если с отрицанием).

:::steps Разбор: P = [10; 40], Q = [20; 60], формула (x ∈ P) → ((x ∈ Q) ∨ (x ∈ A)), найти наименьшую длину A
1. Перепишем: ¬(x ∈ P) ∨ (x ∈ Q) ∨ (x ∈ A).
2. «ИЛИ» ложно, только если все части ложны: x ∈ P, x ∉ Q, x ∉ A.
3. Где x ∈ P, но x ∉ Q? Это отрезок P без пересечения с Q: <span class="hl-red">[10; 20)</span>. Это красная зона.
4. Чтобы формула стала истинной, A должен накрыть всю красную зону. Наименьший такой A = [10; 20] (точка 20 уже входит в Q, но закрыть её не вредно).
5. Длина A: 20 − 10 = **10**.
:::

![Красная зона [10; 20) закрывается отрезком A](images/segments-method.svg)

Подвигай концы отрезка A и посмотри, как исчезают красные зоны, где формула ложна:

:::widget number-line p="10,40" q="20,60" expr="(x∈P) → ((x∈Q) ∨ (x∈A))" a="25,35" min=0 max=70

:::try
Тот же P = [10; 40], Q = [20; 60], но формула (x ∈ Q) → ((x ∈ P) ∨ (x ∈ A)). Какой наименьшей длины A?
---
Ложно, когда x ∈ Q, x ∉ P, x ∉ A. Красная зона — часть Q правее P: (40; 60]. A = [40; 60], длина **20**. Проверь в тренажёре: впиши новую формулу и поставь A от 40 до 60.
:::

### Если A под отрицанием: наибольшая длина

Бывает и наоборот: формула ложна, когда x **внутри** A. Тогда A нельзя пускать в «опасную» зону, и спрашивают **наибольшую** длину A.

:::steps Разбор: P = [15; 40], Q = [21; 63], формула (x ∈ A) → ((x ∈ P) ∨ (x ∈ Q)), наибольшая длина A
1. Ложно, когда x ∈ A, но x не в P и не в Q.
2. Значит, A должен целиком лежать в P ∪ Q.
3. P и Q перекрываются (21 < 40), их объединение — один отрезок [15; 63].
4. Наибольший A = [15; 63], длина **48**.
:::

:::widget number-line p="15,40" q="21,63" expr="(x∈A) → ((x∈P) ∨ (x∈Q))" a="20,50" min=0 max=80

:::warn Не путай «наименьшее» и «наибольшее»
- A стоит так, что формула ложна, когда x **вне** A → A должен **накрыть** зону → ищут **наименьшую** длину.
- Формула ложна, когда x **внутри** A → A должен **избегать** зону → ищут **наибольшую** длину.
:::

## 3. Делимость: ДЕЛ(x, A)

**ДЕЛ(n, m)** означает «n делится на m без остатка». ДЕЛ(12, 4) = 1, ДЕЛ(12, 5) = 0.

Полезные факты:

- x делится и на a, и на b ⇔ x делится на **НОК(a, b)** — наименьшее общее кратное;
- «каждое число, кратное k, делится на A» ⇔ A — **делитель** k;
- если A делит и a, и b, то A делит **НОД(a, b)**.

![Числа, кратные 6, и числа, кратные 4: общие — кратные 12 = НОК(6, 4)](images/multiples.svg)

:::steps Разбор: ДЕЛ(x, A) ∨ (ДЕЛ(x, 6) → ¬ДЕЛ(x, 4)), наибольшее A
1. Ложно, когда ДЕЛ(x, A) = 0 и импликация ложна.
2. Импликация ложна при ДЕЛ(x, 6) = 1 и ¬ДЕЛ(x, 4) = 0, то есть x делится на 6 **и** на 4.
3. x делится на 6 и на 4 ⇔ x делится на НОК(6, 4) = <span class="hl-red">12</span>. Это «опасные» x: 12, 24, 36…
4. Для каждого такого x нужно ДЕЛ(x, A) = 1. Значит, A делит все числа, кратные 12, — A является делителем 12.
5. Наибольший делитель 12 — **12**.
:::

Подбирай A и смотри, где формула ложна (красные клетки). Кнопка найдёт ответ перебором — так же, как это делает программа на Python.

НОК(4, 10) = 20. Например, x = 20 делится на 4 и на 10, но не делится на 40.

### Когда нужно наименьшее A

:::steps Разбор: (ДЕЛ(x, A) ∧ ДЕЛ(x, 6)) → ДЕЛ(x, 18), наименьшее A
1. Ложно, когда x делится на A и на 6, но не делится на 18.
2. x делится на A и на 6 ⇔ x делится на НОК(A, 6). Нужно, чтобы любое такое x делилось на 18: **18 делит НОК(A, 6)**.
3. Перебираем: НОК(1, 6) = 6, НОК(2, 6) = 6, НОК(3, 6) = 6, НОК(4, 6) = 12, НОК(5, 6) = 30, НОК(6, 6) = 6, НОК(7, 6) = 42, НОК(8, 6) = 24, НОК(9, 6) = 18 ✓.
4. Ответ: **9**.
:::

## 4. Поразрядная конъюнкция: x & A

**m & n** — это «И», применённое к каждой паре битов двоичной записи чисел. Числа записывают друг под другом и в каждом разряде применяют ∧.

Пример: 29 & 12.

| | 16 | 8 | 4 | 2 | 1 | |
|---|---|---|---|---|---|---|
| 29 | 1 | 1 | 1 | 0 | 1 | |
| 12 | 0 | 1 | 1 | 0 | 0 | |
| **29 & 12** | 0 | <span class="hl-green">1</span> | <span class="hl-green">1</span> | 0 | 0 | = 12 |

Главные факты:

- **x & A = 0** ⇔ у x и A **нет общих единичных битов**;
- **x & A ≠ 0** ⇔ есть хотя бы один общий единичный бит.

:::widget bitwise a=29 b=12 op=and

:::steps Разбор: (x & 29 ≠ 0) → ((x & 12 = 0) → (x & A ≠ 0)), наименьшее A
1. Ложно, когда x & 29 ≠ 0, x & 12 = 0 и x & A = 0.
2. 29 = 11101₂ = 16 + 8 + 4 + 1, а 12 = 01100₂ = 8 + 4. x & 12 = 0 значит, что у x **нет** битов 8 и 4.
3. Тогда x & 29 ≠ 0 может быть только за счёт битов <span class="hl-red">16</span> или <span class="hl-red">1</span>.
4. «Опасные» x: те, у которых есть бит 16 или бит 1 (и нет 8, 4). Например, x = 1 и x = 16. Для каждого нужно x & A ≠ 0 — значит, у A должен быть и бит 1, и бит 16.
5. Наименьшее A = 16 + 1 = **17**.
:::

## 5. Решение программой

Все виды задания 15 легко проверяются перебором. Идея: перебрать A, и для каждого A проверить формулу на большом диапазоне x функцией `all()`.

```python
def F(x, A):
    return (x % A == 0) or ((x % 6 == 0) <= (x % 4 != 0))   # <= — это импликация

for A in range(1, 1000):
    if all(F(x, A) for x in range(1, 10000)):
        print(A)          # подходящие A; нужен наибольший — смотри последний
```

Для отрезков x перебирают с шагом поменьше (например, 0.25), а концы A — по концам отрезков P и Q.

## 6. Частые ошибки

:::warn Так нельзя
- Искать A, при котором формула **истинна хотя бы иногда**. Нужно — **при любом** x.
- Путать НОК и НОД. «Делится на a и на b» — это **НОК**. «A делит и a, и b» — это **НОД**.
- Забывать, что точки на концах отрезков входят в отрезок: [10; 20] содержит и 10, и 20.
- Считать x & A побитово «в уме» без записи в столбик.
:::

## 7. Шпаргалка урока

:::cheat
- Метод: перепиши → через ∨, найди, где формула может быть ложна, закрой (или обойди) эту зону с помощью A.
- Отрезки: A без ¬ → **накрыть** зону → наименьшая длина; A с ¬ → **не заходить** в зону → наибольшая длина.
- ДЕЛ(x, a) ∧ ДЕЛ(x, b) = ДЕЛ(x, НОК(a, b)).
- «Все кратные k делятся на A» ⇔ A — делитель k.
- x & A = 0 ⇔ нет общих единичных битов.
- Python: импликация `a <= b`, перебор `all(F(x, A) for x in range(...))`.
:::
