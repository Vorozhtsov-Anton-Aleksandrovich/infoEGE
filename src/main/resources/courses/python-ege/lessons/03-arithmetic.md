# Урок 3. Арифметика: целое деление и остаток

В ЕГЭ постоянно нужно разбирать число на цифры, проверять делимость, переводить минуты в часы. Для всего этого есть две операции, которых нет на обычном калькуляторе: **целое деление** `//` и **остаток** `%`. Это, пожалуй, самые важные операции курса.

## 1. Все арифметические операции

| Операция | Пример | Результат | Что делает |
|---|---|---|---|
| `+` | `7 + 2` | `9` | сложение |
| `-` | `7 - 2` | `5` | вычитание |
| `*` | `7 * 2` | `14` | умножение |
| `/` | `7 / 2` | `3.5` | обычное деление, результат всегда дробный |
| `//` | `7 // 2` | `3` | целое деление: сколько раз 2 целиком помещается в 7 |
| `%` | `7 % 2` | `1` | остаток от деления |
| `**` | `7 ** 2` | `49` | возведение в степень |

## 2. Целое деление и остаток — на примере

Вспомни, как в начальной школе делили «с остатком»: 17 конфет делим на 5 детей. Каждому достанется по 3 конфеты, и ещё 2 останутся.

- **3** — это результат целого деления: `17 // 5` → `3`;
- **2** — это остаток: `17 % 5` → `2`.

Проверка всегда одна и та же: `5 · 3 + 2 = 17`. То есть `делимое = делитель · частное + остаток`.

```python
print(17 // 5)   # 3
print(17 % 5)    # 2
print(20 // 5)   # 4
print(20 % 5)    # 0 — разделилось без остатка
print(3 // 5)    # 0 — 5 ни разу не помещается в 3
print(3 % 5)     # 3 — всё осталось в остатке
```

Остаток всегда **меньше** делителя: при делении на 5 остаток может быть только 0, 1, 2, 3 или 4.

## 3. Проверка делимости

Число `n` делится на `k` без остатка, если `n % k` равно нулю. Сравнение «равно» в Python записывается **двумя** знаками: `==`.

```python
print(20 % 5 == 0)   # True — 20 делится на 5
print(21 % 5 == 0)   # False — не делится
```

`True` значит «правда», `False` — «ложь». Такие проверки понадобятся в следующем уроке про условия.

Частные случаи, которые нужно знать наизусть:

| Запись | Значит |
|---|---|
| `n % 2 == 0` | n чётное |
| `n % 2 == 1` | n нечётное (для положительных n) |
| `n % 10 == 0` | n оканчивается на 0 |
| `n % k == 0` | n делится на k |

## 4. Цифры числа

Здесь работает простая идея: деление на 10 «отрезает» цифры.

- `n % 10` — **последняя цифра** числа (остаток от деления на 10);
- `n // 10` — число **без последней цифры**.

```python
n = 2025
print(n % 10)    # 5   — последняя цифра
print(n // 10)   # 202 — без последней цифры
print(n % 100)   # 25  — две последние цифры
print(n // 100)  # 20  — без двух последних
```

Почему так? 2025 = 202 · 10 + 5. Значит, при делении на 10 частное 202, а остаток 5.

### Цифры трёхзначного числа

Пусть `n = 739`. Достанем каждую цифру:

| Цифра | Формула | Вычисление | Результат |
|---|---|---|---|
| сотни | `n // 100` | 739 // 100 | `7` |
| десятки | `n // 10 % 10` | 739 // 10 = 73, потом 73 % 10 | `3` |
| единицы | `n % 10` | 739 % 10 | `9` |

Формулу для десятков разберём подробно: сначала `n // 10` отрезает последнюю цифру (было 739, стало 73), а потом `% 10` берёт последнюю цифру того, что осталось (3). Операции выполняются **слева направо**, потому что `//` и `%` имеют одинаковый приоритет.

## 5. Порядок действий

Python считает в таком порядке:

1. скобки `( )`;
2. степень `**`;
3. умножение и все виды деления: `*`, `/`, `//`, `%` — слева направо;
4. сложение и вычитание: `+`, `-` — слева направо.

```python
print(2 + 3 * 4)      # 14
print((2 + 3) * 4)    # 20
print(2 * 3 ** 2)     # 18: сначала 3 ** 2 = 9, потом 2 · 9
print(10 - 4 - 3)     # 3: слева направо, (10 - 4) - 3
print(7 + 10 // 3)    # 10: сначала 10 // 3 = 3, потом 7 + 3
```

Если сомневаешься — ставь скобки. Лишние скобки ничего не ломают, а читать код становится проще.

## 6. Переводы единиц

Целое деление и остаток идеально подходят для перевода «минуты → часы и минуты».

Прошло 150 минут. Сколько это часов и минут?

```python
n = 150
hours = n // 60      # 2 — сколько раз по 60 минут помещается
minutes = n % 60     # 30 — сколько минут осталось
print(hours, minutes)   # 2 30
```

Так же переводят секунды в минуты, копейки в рубли, дни в недели.

## 7. Округление вверх

Задача: 25 учеников, за партой сидят по двое. Сколько нужно парт? `25 // 2 = 12`, но тогда одному ученику не хватит места. Нужно **13** — округлить вверх.

Приём: прибавь к делимому `делитель − 1` и только потом дели нацело:

```python
n = 25
print((n + 1) // 2)   # 13
n = 24
print((n + 1) // 2)   # 12 — для чётного ничего лишнего не добавилось
```

В общем виде: «округлить `n / k` вверх» — это `(n + k - 1) // k`.

## 8. Дробные числа: осторожно

Обычное деление `/` всегда даёт дробное число (`float`), даже если делится нацело: `6 / 3` → `2.0`. Если в задаче нужен целый ответ, используй `//`.

Дробные числа компьютер хранит **приближённо**:

```python
print(0.1 + 0.2)   # 0.30000000000000004
```

Это не ошибка Python, так устроены все компьютеры. Поэтому в задачах ЕГЭ старайся считать **в целых числах**.

## Частые ошибки

- Написать `/` вместо `//` и получить ответ `3.0` вместо `3`. Тест не пройдёт: `3.0` и `3` — разный вывод.
- Перепутать `//` и `%`: `//` — сколько раз поместилось, `%` — что осталось.
- Написать `=` вместо `==` при проверке: `n % 2 = 0` — это ошибка `SyntaxError`.

## Проверь себя

Что выведет программа?

```python
n = 4815
print(n % 10, n // 1000, n // 10 % 10)
print(100 // 7, 100 % 7)
```
