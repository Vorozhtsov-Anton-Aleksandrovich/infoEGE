# Урок 7. Строки

Строка — это текст: слово, предложение, запись числа. На ЕГЭ строки нужны в заданиях 8, 12, 14, 24 и везде, где с числом удобнее работать как с набором символов.

## 1. Строка — это цепочка символов

Строка состоит из **символов**: букв, цифр, пробелов, знаков. Каждый символ стоит на своём месте, и у каждого места есть номер — **индекс**.

![Индексы строки и срезы](images/string-index.svg)

```
строка:   P  Y  T  H  O  N
индекс:   0  1  2  3  4  5
с конца: -6 -5 -4 -3 -2 -1
```

> ⚠️ Индексы начинаются **с нуля**, а не с единицы. Первый символ — `s[0]`, второй — `s[1]`.

```python
s = 'PYTHON'
print(s[0])     # P — первый символ
print(s[2])     # T — третий символ
print(s[-1])    # N — последний
print(s[-2])    # O — предпоследний
print(len(s))   # 6 — длина строки, количество символов
```

`len` (от length — длина) возвращает количество символов. Последний символ имеет индекс `len(s) - 1`, поэтому для строки длины 6 это `s[5]`. Если обратиться к `s[6]`, будет ошибка `IndexError: string index out of range` (индекс за пределами строки).

Отрицательные индексы считают с конца: `s[-1]` — всегда последний символ, какой бы длины ни была строка.

## 2. Срезы — кусок строки

**Срез** `s[начало:конец]` вырезает часть строки. Как и в `range`, **правая граница не входит**.

```python
s = 'PYTHON'
print(s[1:4])   # YTH — символы с индексами 1, 2, 3
print(s[:3])    # PYT — с начала до индекса 3 (не включая)
print(s[3:])    # HON — с индекса 3 до конца
print(s[:])     # PYTHON — вся строка
print(s[::2])   # PTO — каждый второй символ
print(s[::-1])  # NOHTYP — задом наперёд
```

| Срез | Что даёт |
|---|---|
| `s[:k]` | первые k символов |
| `s[k:]` | всё, кроме первых k |
| `s[-k:]` | последние k символов |
| `s[::-1]` | строка задом наперёд |

## 3. Строки нельзя менять

Строку **нельзя изменить по индексу**:

```python
s = 'кот'
s[0] = 'р'      # ОШИБКА: TypeError: 'str' object does not support item assignment
```

Зато можно собрать **новую** строку и положить её в ту же переменную:

```python
s = 'кот'
s = 'р' + s[1:]
print(s)        # рот
```

## 4. Операции со строками

```python
print('ab' + 'cd')    # abcd — склеивание
print('ab' * 3)       # ababab — повторение
print('ab' == 'ab')   # True — сравнение
print('a' in 'cat')   # True — есть ли подстрока
print('dog' in 'cat') # False
```

Превращение числа в строку и обратно:

```python
n = 2025
s = str(n)       # '2025'
print(len(s))    # 4 — количество цифр числа
print(s[0])      # 2 — первая цифра (это символ '2', а не число!)
print(int(s[0]) + 1)   # 3 — чтобы считать, превращаем обратно в число
```

## 5. Перебор символов в цикле

Цикл `for` умеет перебирать **символы строки** напрямую:

```python
for c in 'кот':
    print(c)
```

```
к
о
т
```

На каждом шаге в переменную `c` попадает очередной символ. Так удобно что-нибудь считать:

```python
s = input()
cnt = 0
for c in s:
    if c in 'aeiou':     # c — одна из гласных?
        cnt += 1
print(cnt)
```

Если нужен не только символ, но и его **номер** (например, чтобы сравнить с соседним), перебирают индексы:

```python
s = 'AABCC'
for i in range(len(s) - 1):     # до предпоследнего, чтобы у s[i] был сосед справа
    if s[i] == s[i + 1]:
        print('одинаковые на позициях', i, 'и', i + 1)
```

`range(len(s) - 1)` — потому что у последнего символа нет соседа справа, и `s[i + 1]` вышел бы за пределы строки.

## 6. Методы строк

**Метод** — это команда, которую пишут **через точку** после строки: `s.upper()`. Самые нужные:

| Метод | Что делает | Пример | Результат |
|---|---|---|---|
| `s.upper()` | все буквы большие | `'Кот'.upper()` | `'КОТ'` |
| `s.lower()` | все буквы маленькие | `'Кот'.lower()` | `'кот'` |
| `s.count(x)` | сколько раз встречается `x` | `'банан'.count('а')` | `2` |
| `s.replace(a, b)` | заменить все `a` на `b` | `'1212'.replace('1', '0')` | `'0202'` |
| `s.replace(a, b, 1)` | заменить только **первое** `a` | `'1212'.replace('1', '0', 1)` | `'0212'` |
| `s.find(x)` | индекс первого вхождения или `-1` | `'кот'.find('о')` | `1` |
| `s.split()` | разрезать по пробелам | `'я учу код'.split()` | `['я', 'учу', 'код']` |
| `s.strip()` | убрать пробелы и переводы строк по краям | `' да \n'.strip()` | `'да'` |
| `s.isdigit()` | состоит ли только из цифр | `'123'.isdigit()` | `True` |

Методы **не меняют** строку, а возвращают новую. Поэтому результат нужно сохранить:

```python
s = 'кот'
s.upper()        # создалась строка 'КОТ' и сразу пропала
print(s)         # кот
s = s.upper()    # а так сохранили
print(s)         # КОТ
```

`count` считает вхождения **без наложений**: `'aaaa'.count('aa')` даст `2`, а не `3`.

## 7. Сумма цифр числа через строку

В уроке 6 мы считали сумму цифр через `while`. Через строку тоже можно:

```python
n = 2025
s = 0
for c in str(n):
    s += int(c)
print(s)    # 9
```

## 8. Задание 12 ЕГЭ: «Редактор»

В задании 12 есть исполнитель, который заменяет одни куски строки на другие. Например: «**пока** в строке есть `11`, заменить **первое** `11` на `2`». На Python это пишется почти дословно:

```python
s = '1' * 7          # '1111111' — семь единиц
while '11' in s:     # пока есть '11'
    s = s.replace('11', '2', 1)   # заменить первое вхождение
print(s)             # 2221
```

Посмотрим, как меняется строка: `1111111` → `211111` → `22111` → `2221`. В строке `2221` пары `11` нет, цикл закончился.

## 9. Задание 24: самая длинная цепочка

Задача: найти длину самой длинной цепочки **одинаковых** символов подряд. Например, в `ABBBCCD` это `BBB`, длина 3.

Идея: идём по строке и держим два счётчика:

- `cur` — длина **текущей** цепочки;
- `best` — самая длинная из встреченных.

Если символ такой же, как предыдущий, цепочка продолжается (`cur += 1`). Если другой — начинается новая цепочка (`cur = 1`).

```python
s = input()
cur = 1
best = 1
for i in range(1, len(s)):        # начинаем с 1: сравниваем с предыдущим s[i - 1]
    if s[i] == s[i - 1]:
        cur += 1
    else:
        cur = 1
    if cur > best:
        best = cur
print(best)
```

Трассировка для `ABBBCCD`:

| i | s[i] | s[i − 1] | cur | best |
|---|---|---|---|---|
| — | — | — | 1 | 1 |
| 1 | B | A | 1 | 1 |
| 2 | B | B | 2 | 2 |
| 3 | B | B | 3 | 3 |
| 4 | C | B | 1 | 3 |
| 5 | C | C | 2 | 3 |
| 6 | D | C | 1 | 3 |

Ответ: `3`. Этот шаблон с `cur` и `best` нужно знать наизусть: в задании 24 меняется только условие «продолжается ли цепочка».

## Частые ошибки

| Ошибка | Что не так |
|---|---|
| `s[len(s)]` | индекса `len(s)` нет, последний символ — `s[len(s) - 1]` или `s[-1]` |
| `s.upper()` без присваивания | строка не изменится, нужно `s = s.upper()` |
| сравнить символ `'5'` с числом `5` | `'5' == 5` — это `False`: символ и число разные вещи |
| `s[0] = 'x'` | строку нельзя менять, собирай новую |
