# Урок 6. Цикл while

Цикл `for` хорош, когда заранее известно, сколько раз повторять. Но бывает иначе: «делай, **пока** не выполнится условие». Например, «отрезай от числа последние цифры, пока оно не станет нулём». Для этого есть цикл `while` (по-английски «пока»).

## 1. Как работает `while`

```python
n = 1
while n < 100:
    print(n)
    n = n * 2
print('конец')
```

Читается так: «**пока** `n < 100`, выводи `n` и удваивай его».

![Схема цикла while](images/while-flow.svg)

Как Python выполняет `while`:

1. Проверяет условие.
2. Если оно **истинно**, выполняет тело цикла и **возвращается к шагу 1**.
3. Если оно **ложно**, пропускает тело и переходит к строке после цикла.

Трассировка:

| Проверка | n | Условие n < 100 | Что делаем |
|---|---|---|---|
| 1 | 1 | да | выводим 1, n = 2 |
| 2 | 2 | да | выводим 2, n = 4 |
| 3 | 4 | да | выводим 4, n = 8 |
| … | … | … | … |
| 7 | 64 | да | выводим 64, n = 128 |
| 8 | 128 | **нет** | выходим из цикла |

Выведет 1, 2, 4, 8, 16, 32, 64 (каждое на своей строке), а потом `конец`.

Если условие ложно с самого начала, тело не выполнится **ни разу**.

## 2. `for` и `while` — одно и то же двумя способами

Любой `for` можно переписать через `while`. Вот вывод чисел от 1 до 5:

```python
# через for
for i in range(1, 6):
    print(i)

# через while
i = 1             # 1. начальное значение — до цикла
while i <= 5:     # 2. условие продолжения
    print(i)
    i += 1        # 3. изменение — внутри цикла
```

У `while` все три части пишутся **отдельно и вручную**. Если забыть `i += 1`, `i` навсегда останется равным 1, условие всегда будет истинным, и цикл не закончится никогда.

## 3. Бесконечный цикл

```python
i = 1
while i <= 5:
    print(i)      # забыли i += 1 — цикл бесконечный!
```

Программа «зависнет» и будет выводить единицы без конца. На этом сайте программа, которая работает дольше нескольких секунд, будет остановлена с сообщением «превышено время».

Чтобы такого не было, проверяй: **меняется ли внутри цикла переменная из условия, и приближает ли это изменение выход из цикла?**

## 4. Главный приём: цифры числа

Помнишь из урока 3: `n % 10` — последняя цифра, `n // 10` — число без неё. Если повторять это в цикле, можно перебрать **все** цифры числа, справа налево:

```python
n = 2025
s = 0
while n > 0:
    s += n % 10     # добавляем последнюю цифру
    n //= 10        # отрезаем её
print(s)            # 9
```

Трассировка:

| Шаг | n | n % 10 | s | n // 10 |
|---|---|---|---|---|
| 1 | 2025 | 5 | 5 | 202 |
| 2 | 202 | 2 | 7 | 20 |
| 3 | 20 | 0 | 7 | 2 |
| 4 | 2 | 2 | 9 | 0 |
| — | 0 | — | — | условие `n > 0` ложно, выход |

Цикл сам «понимает», сколько у числа цифр: он идёт, пока от числа хоть что-то осталось. Поэтому здесь `while`, а не `for`.

С этим же шаблоном легко:

- посчитать **количество** цифр (вместо `s += n % 10` пиши `cnt += 1`);
- найти **максимальную** цифру;
- посчитать, сколько цифр **чётных**.

## 5. `break` — досрочный выход

Команда `break` («прервать») немедленно завершает цикл, даже если условие ещё истинно. Обычно её ставят внутри `if`:

```python
# первое трёхзначное число, которое делится на 17 и оканчивается на 3
for n in range(100, 1000):
    if n % 17 == 0 and n % 10 == 3:
        print(n)     # 153
        break        # дальше искать не нужно
```

Без `break` программа вывела бы **все** такие числа.

`break` работает и в `for`, и в `while`. Часто его используют с «вечным» циклом `while True:` — он крутится, пока внутри не сработает `break`:

```python
n = 1
while True:
    if n * n > 1000:
        break
    n += 1
print(n)    # 32 — первое число, квадрат которого больше 1000
```

## 6. `continue` — пропустить шаг

`continue` («продолжить») пропускает остаток тела и сразу переходит к следующей итерации:

```python
for i in range(1, 11):
    if i % 3 == 0:
        continue      # кратные трём пропускаем
    print(i, end=' ')
```

```
1 2 4 5 7 8 10
```

## 7. Перебор делителей и простые числа

**Простое число** — это число больше 1, которое делится только на 1 и на само себя: 2, 3, 5, 7, 11, 13… Чтобы проверить, простое ли `n`, переберём возможные делители от 2:

```python
n = int(input())
prime = n > 1        # для 0 и 1 сразу «не простое»
d = 2
while d * d <= n:    # делители достаточно проверять до корня из n
    if n % d == 0:   # нашли делитель — значит не простое
        prime = False
        break
    d += 1
if prime:
    print('YES')
else:
    print('NO')
```

Почему только до корня? Если `n = a · b` и оба множителя больше корня из `n`, то их произведение больше `n` — так не бывает. Значит, если у `n` есть делитель, то **один из пары** обязательно не больше корня. Условие `d * d <= n` и значит «d не больше корня из n». Для числа около миллиарда это 31 623 проверки вместо миллиарда.

Переменная `prime` здесь — **флаг**: она хранит `True` или `False`, «пока что простое» или «уже точно нет». Такой приём встречается часто.

## 8. Числа Фибоначчи

Последовательность Фибоначчи: 1, 1, 2, 3, 5, 8, 13, … — каждое число равно сумме двух предыдущих. Чтобы её считать, храним **два последних** числа:

```python
a, b = 1, 1
for i in range(5):
    print(a, end=' ')
    a, b = b, a + b
```

```
1 1 2 3 5
```

Строка `a, b = b, a + b` одновременно сдвигает пару вперёд: новое `a` — это старое `b`, новое `b` — сумма старых.

## Частые ошибки

| Ошибка | Что получится |
|---|---|
| забыли изменить переменную из условия | бесконечный цикл |
| `while n > 0` для `n = 0` | тело не выполнится ни разу — у нуля «нет цифр». Если это важно, обработай ноль отдельно |
| сравнение `=` вместо `==` в условии | `SyntaxError` |
| `break` вне цикла | `SyntaxError: 'break' outside loop` |

## Проверь себя

Что выведет программа?

```python
n = 50
cnt = 0
while n > 1:
    n //= 2
    cnt += 1
print(n, cnt)
```

<details>
<summary>Показать ответ</summary>

`1 5`

n меняется так: 50 → 25 → 12 → 6 → 3 → 1. Пять делений, после них `n = 1`, и условие `n > 1` стало ложным.

</details>

## Практика

В каждой задаче подумай: известно ли заранее число повторов? Если да — удобнее `for`, если нет — `while`.
