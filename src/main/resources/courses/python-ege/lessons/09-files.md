# Урок 9. Работа с файлами

В заданиях 9, 17, 18, 22, 24, 26, 27 данные лежат в файле. Руками их не обработать — нужна программа.

## 1. Где должен лежать файл

![Файл должен лежать рядом с программой](images/file-read.svg)

Самый простой способ: **положи файл в ту же папку, где сохранена программа**, и открывай по имени: `open('17.txt')`.

- **IDLE**: сохрани `.py` в ту же папку, что и `17.txt`, и запускай через F5.
- **PyCharm**: перетащи файл в панель Project (в папку проекта).

Если Python пишет `FileNotFoundError` — файл не там. Можно указать полный путь: `open(r'C:\Users\Имя\Desktop\17.txt')` (буква `r` перед строкой нужна из-за обратных слешей).

На этой платформе файл к задаче уже «лежит рядом» — просто открывай его по имени из условия.

## 2. Чтение

Весь файл одной строкой (задание 24):

```python
s = open('24.txt').readline().strip()
```

`.strip()` убирает перевод строки `\n` в конце — без него длина будет на 1 больше.

Числа по одному в строке (задание 17):

```python
a = [int(x) for x in open('17.txt')]
```

Первая строка — количество, дальше пары чисел (задания 26, 27):

```python
f = open('27.txt')
n = int(f.readline())
pairs = []
for i in range(n):
    x, y = map(int, f.readline().split())
    pairs.append((x, y))
```

Таблица через пробелы/табуляции (задание 9) — каждую строку разбиваем `split()`:

```python
for line in open('9.txt'):
    row = list(map(int, line.split()))
    ...
```

## 3. Конструкция `with`

```python
with open('17.txt') as f:
    a = [int(x) for x in f]
```

`with` сам закроет файл. Для ЕГЭ не обязательно, но это хороший стиль.

## 4. Таблицы Excel (`.xlsx`) и `.csv`

Если дан `.xlsx`, проще всего в Excel сделать **Файл → Сохранить как → Текст (разделитель — табуляция) (*.txt)** и читать как текст. `.csv` читается так же, только `split(';')` или `split(',')`.

## 5. Кодировка

Если в файле русские буквы и появляется `UnicodeDecodeError`, укажи кодировку:

```python
open('9.txt', encoding='utf-8')
```
