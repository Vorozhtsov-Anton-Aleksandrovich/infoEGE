# Урок 6. Строки

Строки нужны в заданиях 8, 12, 14, 24 — и вообще везде, где работаешь с цифрами числа как с символами.

## 1. Индексы и срезы

![Индексы строки и срезы](images/string-index.svg)

```python
s = 'PYTHON'
print(s[0])     # P — первый символ
print(s[-1])    # N — последний
print(len(s))   # 6 — длина
print(s[1:4])   # YTH — с 1 по 3 (правая граница не входит)
print(s[:3])    # PYT — первые 3
print(s[3:])    # HON — с 3 до конца
print(s[::-1])  # NOHTYP — задом наперёд
```

Строку **нельзя изменить** по индексу: `s[0] = 'p'` → ошибка. Создавай новую строку.

## 2. Перебор символов

```python
s = input()
cnt = 0
for c in s:
    if c in 'AEIOU':
        cnt += 1
print(cnt)
```

Перебор с индексом — когда нужно сравнивать соседей:

```python
for i in range(len(s) - 1):
    if s[i] == s[i + 1]:
        print('есть два одинаковых подряд')
```

## 3. Главные методы строк

| Метод | Что делает | Пример |
|---|---|---|
| `s.count('ab')` | сколько раз встречается (без наложений) | `'ababab'.count('ab')` → 3 |
| `s.replace(a, b)` | заменить все `a` на `b` | `'1212'.replace('1', '0')` → `'0202'` |
| `s.replace(a, b, 1)` | заменить только первое | — |
| `s.find('x')` | индекс первого вхождения, или `-1` | — |
| `'x' in s` | есть ли подстрока | `True` / `False` |
| `s.split()` | разбить по пробелам в список | `'a b c'.split()` → `['a','b','c']` |
| `s.upper()`, `s.lower()` | регистр | — |
| `s.isdigit()` | состоит ли из цифр | — |

## 4. Операции

```python
'ab' + 'cd'   # 'abcd'
'ab' * 3      # 'ababab'
str(123)      # '123' — число в строку
```

Сумма цифр числа через строку:

```python
n = 2025
print(sum(int(c) for c in str(n)))   # 9
```

## 5. Задание 12 ЕГЭ (Редактор) на Python

Алгоритм «пока есть `'11'` — заменить первое `'11'` на `'2'`» пишется почти дословно:

```python
s = '1' * 7
while '11' in s:
    s = s.replace('11', '2', 1)
print(s)    # 2221
```

## 6. Задание 24: самая длинная цепочка

Шаблон «счётчик текущей длины + максимум»:

```python
s = input()
cur = 1
best = 1
for i in range(1, len(s)):
    if s[i] == s[i - 1]:
        cur += 1
    else:
        cur = 1
    best = max(best, cur)
print(best)
```
