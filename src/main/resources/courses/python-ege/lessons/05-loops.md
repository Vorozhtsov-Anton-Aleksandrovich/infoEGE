# Урок 5. Циклы for и while

Цикл повторяет действия много раз. Именно из-за циклов программа решает ЕГЭ-задачи на перебор за секунду.

## 1. Цикл `for` и `range`

```python
for i in range(5):
    print(i)        # 0 1 2 3 4 (каждое на новой строке)
```

![Как работает range](images/range.svg)

| Запись | Значения |
|---|---|
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(2, 6)` | 2, 3, 4, 5 — **правая граница не входит** |
| `range(1, 10, 2)` | 1, 3, 5, 7, 9 — шаг 2 |
| `range(10, 0, -1)` | 10, 9, …, 1 — обратный отсчёт |

Чтобы перебрать числа от `a` до `b` **включительно**: `range(a, b + 1)`.

## 2. Накопление: сумма, количество, максимум

Это три шаблона, которые встречаются в половине задач.

```python
n = int(input())
s = 0          # сумма — начинаем с 0
cnt = 0        # количество — с 0
mx = -10**9    # максимум — с очень маленького числа
for i in range(n):
    x = int(input())
    s += x
    if x % 2 == 0:
        cnt += 1
    if x > mx:
        mx = x
print(s, cnt, mx)
```

## 3. Цикл `while`

`while` повторяет, **пока условие истинно**. Удобен, когда заранее неизвестно, сколько шагов.

```python
n = 2025
s = 0
while n > 0:
    s += n % 10    # берём последнюю цифру
    n //= 10       # отбрасываем её
print(s)           # 9 = 2+0+2+5
```

![Схема цикла while](images/while-flow.svg)

Если условие никогда не станет ложным — цикл бесконечный, программа зависнет. Проверяй, что переменная в условии **меняется** внутри цикла.

## 4. `break` и `continue`

- `break` — сразу выйти из цикла;
- `continue` — пропустить остаток тела и перейти к следующему шагу.

```python
for n in range(100, 1000):
    if n % 17 == 0 and n % 10 == 3:
        print(n)    # первое такое число
        break
```

## 5. Вложенные циклы

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(i * j, end=' ')
    print()
```

Вывод:

```
1 2 3
2 4 6
3 6 9
```

Внутренний цикл полностью проходит для **каждого** шага внешнего.

## 6. Как это используют на ЕГЭ

Задание 5, 14, 15, 16, 17, 23, 25 — почти всегда «перебери все варианты в цикле и проверь условие». Например, «сколько чисел от 1 до 10 000 делятся на 7 и не делятся на 3?»:

```python
cnt = 0
for n in range(1, 10001):
    if n % 7 == 0 and n % 3 != 0:
        cnt += 1
print(cnt)
```
