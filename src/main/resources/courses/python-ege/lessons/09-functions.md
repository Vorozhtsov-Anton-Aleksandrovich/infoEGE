# Урок 9. Функции

Ты уже пользовался функциями: `print`, `len`, `max`, `int`. Каждая из них — это готовый кусок кода с именем: пишешь имя, в скобках передаёшь данные, получаешь результат. В этом уроке научимся создавать **свои** функции. На ЕГЭ они нужны в заданиях 16 (рекурсия), 23, 25 (делители) и просто чтобы код был понятным.

## 1. Зачем нужны функции

Допустим, в программе три раза нужно проверить, простое ли число. Можно три раза скопировать одинаковый цикл, но это длинно, и если в нём ошибка — исправлять придётся в трёх местах. Лучше написать проверку **один раз**, дать ей имя и вызывать по имени.

## 2. Как создать функцию

```python
def square(x):
    return x * x

print(square(5))      # 25
print(square(3) + 1)  # 10
```

![Функция: аргументы → тело → return](images/function.svg)

Разберём по частям:

| Часть | Что это |
|---|---|
| `def` | ключевое слово «определить функцию» (от define) |
| `square` | имя функции, правила те же, что для переменных |
| `(x)` | **параметр**: имя, под которым функция получит переданное значение |
| `:` | двоеточие |
| `    return x * x` | **тело** функции с отступом |
| `return` | «вернуть»: отдать результат тому, кто вызвал функцию |

Строки с `def` сами по себе **ничего не выполняют**: они только объясняют Python, что такое `square`. Код внутри функции выполнится, когда функцию **вызовут**: `square(5)`.

### Что происходит при вызове

Когда Python видит `square(5)`:

1. Кладёт 5 в параметр `x`.
2. Выполняет тело функции: `x * x` = 25.
3. `return` отдаёт 25 обратно. Вызов `square(5)` как бы **заменяется** на 25.
4. `print(25)` выводит результат.

Значение, которое передают при вызове (здесь 5), называется **аргументом**.

### Функцию нужно определить до вызова

Python читает программу сверху вниз. Если вызвать функцию раньше, чем написан её `def`, будет ошибка `NameError: name 'square' is not defined`. Поэтому функции пишут **в начале** программы, а основной код — после них.

## 3. `return` завершает функцию

Как только выполнился `return`, функция **сразу заканчивается**, строки после него не выполняются:

```python
def sign(n):
    if n > 0:
        return 1
    if n < 0:
        return -1
    return 0

print(sign(-7))   # -1
```

При `n = -7` первое условие ложно, второе истинно — выполняется `return -1`, и до `return 0` дело не доходит.

### Функция без `return`

Если в функции нет `return`, она возвращает специальное значение `None` (ничего). Такие функции тоже бывают: они что-то делают, например выводят на экран, но результат не возвращают.

```python
def hello(name):
    print('Привет,', name)

hello('Аня')          # Привет, Аня
x = hello('Петя')     # Привет, Петя
print(x)              # None
```

Не путай `print` и `return`: `print` **показывает** значение на экране, `return` **отдаёт** его программе, чтобы с ним можно было дальше считать.

## 4. Несколько параметров

Параметров может быть несколько, через запятую. Аргументы при вызове передаются **в том же порядке**:

```python
def rect_area(a, b):
    return a * b

print(rect_area(3, 4))   # 12: a = 3, b = 4
```

Функция может вернуть и несколько значений сразу:

```python
def min_max(a, b):
    if a < b:
        return a, b
    return b, a

lo, hi = min_max(9, 4)
print(lo, hi)    # 4 9
```

## 5. Переменные внутри функции

Переменные, созданные внутри функции, **живут только внутри неё**. Снаружи их не видно:

```python
def f():
    t = 10
    return t * 2

print(f())    # 20
print(t)      # ОШИБКА: NameError: name 't' is not defined
```

Это удобно: можно не бояться, что переменная `i` внутри функции испортит переменную `i` в основной программе.

## 6. Функция-проверка: простое число

В уроке 6 мы проверяли число на простоту. Оформим это в функцию:

```python
def is_prime(n):
    if n < 2:
        return False
    d = 2
    while d * d <= n:
        if n % d == 0:
            return False     # нашли делитель — сразу выходим
        d += 1
    return True              # делителей не нашлось

print(is_prime(7))    # True
print(is_prime(91))   # False: 91 = 7 · 13
```

`return` внутри цикла заменяет `break` и флаг: как только найден делитель, функция сразу отвечает `False`.

Теперь посчитать простые числа на отрезке — дело пары строк:

```python
cnt = 0
for x in range(1, 101):
    if is_prime(x):
        cnt += 1
print(cnt)    # 25
```

## 7. Делители числа (задание 25)

Найдём все делители числа. Перебираем `d` до корня, и если `d` — делитель, то `n // d` — тоже делитель (его «пара»):

```python
def divisors(n):
    res = []
    d = 1
    while d * d <= n:
        if n % d == 0:
            res.append(d)
            if d != n // d:          # чтобы для 36 не добавить 6 дважды
                res.append(n // d)
        d += 1
    return sorted(res)

print(divisors(36))   # [1, 2, 3, 4, 6, 9, 12, 18, 36]
```

Для `n = 36`: `d = 1` даёт пару 1 и 36, `d = 2` — 2 и 18, `d = 3` — 3 и 12, `d = 4` — 4 и 9, `d = 6` — 6 и 6 (добавляем один раз). На `d = 7` цикл заканчивается, потому что 7 · 7 = 49 > 36.

## 8. Рекурсия (задание 16)

**Рекурсия** — это когда функция вызывает **саму себя**. В задании 16 функции именно так и заданы, например:

- `F(1) = 1`;
- `F(n) = F(n − 1) + 2·n` при `n > 1`.

На Python это переписывается почти дословно:

```python
def F(n):
    if n == 1:                 # базовый случай: ответ известен сразу
        return 1
    return F(n - 1) + 2 * n    # рекурсивный случай

print(F(4))   # 19
```

Как считается `F(4)`:

```
F(4) = F(3) + 8
       F(3) = F(2) + 6
              F(2) = F(1) + 4
                     F(1) = 1
              F(2) = 1 + 4 = 5
       F(3) = 5 + 6 = 11
F(4) = 11 + 8 = 19
```

Функция «спускается» до `F(1)`, а потом результаты «поднимаются» обратно.

**Базовый случай обязателен.** Без него функция вызывала бы себя бесконечно, и Python остановил бы её с ошибкой `RecursionError: maximum recursion depth exceeded` (превышена глубина рекурсии).

### Глубокая рекурсия

Python разрешает примерно 1000 вложенных вызовов. Если в задаче нужно `F(5000)`, увеличь лимит в начале программы:

```python
import sys
sys.setrecursionlimit(10000)
```

### Кэш: чтобы не считать одно и то же

Возьмём функцию, которая вызывает себя **дважды**: `F(n) = F(n − 1) + F(n − 2)`. Для `F(40)` она будет пересчитывать одни и те же значения миллионы раз и работать очень долго. Помогает **кэш** — запоминание уже посчитанных ответов:

```python
from functools import lru_cache

@lru_cache(None)
def F(n):
    if n <= 2:
        return 1
    return F(n - 1) + F(n - 2)

print(F(90))   # мгновенно
```

Первая строка подключает `lru_cache` из стандартной библиотеки, а строка `@lru_cache(None)` прямо над `def` включает запоминание для этой функции. Больше ничего менять не нужно.

## Частые ошибки

| Ошибка | Что не так |
|---|---|
| вызов функции раньше `def` | `NameError` |
| `print` вместо `return` внутри функции | функция выводит число, но возвращает `None`, и `F(3) + 1` выдаст ошибку `TypeError` |
| забыт базовый случай в рекурсии | `RecursionError` |
| `def f(x)` без двоеточия | `SyntaxError: expected ':'` |
| `return` вне функции | `SyntaxError: 'return' outside function` |

## Проверь себя

Что выведет программа?

```python
def g(a, b):
    if a > b:
        return a - b
    return b - a

print(g(3, 10), g(10, 3), g(g(1, 5), 2))
```
