# Урок 3. Переменные, ввод, вывод, арифметика

## 1. Переменная — подписанная коробка

Переменная хранит значение под именем. Знак `=` значит «положи справа в коробку слева», а не «равно».

```python
a = 5
b = a + 2   # b = 7
a = a * 10  # a = 50, старое значение 5 пропало
```

![Переменные как подписанные коробки](images/variables.svg)

Правила имён: латинские буквы, цифры, `_`; не начинать с цифры; регистр важен (`count` и `Count` — разные переменные).

## 2. Типы данных

| Тип | Пример | Что это |
|---|---|---|
| `int` | `42`, `-7`, `10**100` | целое число (любой длины!) |
| `float` | `3.14`, `2.0` | дробное число |
| `str` | `'abc'`, `"10"` | строка (текст) |
| `bool` | `True`, `False` | логическое значение |

`'10'` и `10` — разные вещи: `'10' + '5'` даёт `'105'`, а `10 + 5` даёт `15`.

Узнать тип: `type(x)`. Перевести: `int('17')` → `17`, `str(17)` → `'17'`, `float('2.5')` → `2.5`.

## 3. Арифметика

| Операция | Пример | Результат |
|---|---|---|
| `+ - *` | `7 * 3` | `21` |
| `/` деление | `7 / 2` | `3.5` (всегда float) |
| `//` целая часть | `7 // 2` | `3` |
| `%` остаток | `7 % 2` | `1` |
| `**` степень | `2 ** 8` | `256` |

`//` и `%` — самые важные операции на ЕГЭ:

- `n % 10` — последняя цифра числа;
- `n // 10` — число без последней цифры;
- `n % 2 == 0` — число чётное;
- `n % k == 0` — `n` делится на `k`.

```python
n = 2025
print(n % 10)    # 5
print(n // 10)   # 202
print(n % 100)   # 25 — две последние цифры
```

Сокращённая запись: `x += 3` то же, что `x = x + 3`. Так же работают `-=`, `*=`, `//=`, `%=`.

## 4. Вывод: `print`

```python
print(5)              # 5
print('a', 'b', 3)    # a b 3   — через пробел
print('a', 'b', sep='')   # ab  — без разделителя
print(1, 2, 3, sep=', ')  # 1, 2, 3
print('без перевода строки', end=' ')
print('продолжение')
```

## 5. Ввод: `input`

`input()` **всегда возвращает строку**. Для чисел оборачивай в `int()`:

```python
n = int(input())     # ввод: 7   → n = 7
```

Несколько чисел в одной строке через пробел:

```python
a, b = map(int, input().split())   # ввод: 3 8
print(a + b)                       # 11
```

Разберём по частям: `input()` → `'3 8'`, `.split()` → `['3', '8']`, `map(int, ...)` превращает каждое в число.

Каждый вызов `input()` читает **одну строку**. Если числа на разных строках — вызывай `input()` несколько раз.

## 6. Частая ошибка

```python
a = input()
b = input()
print(a + b)   # ввод 2 и 3 → выведет 23, а не 5!
```

Забыли `int()` — сложились строки.

## Практика

Во всех задачах вводи данные через `input()` **без текста в скобках** и выводи только ответ.
