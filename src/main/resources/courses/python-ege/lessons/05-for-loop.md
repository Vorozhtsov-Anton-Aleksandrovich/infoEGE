# Урок 5. Цикл for

Допустим, нужно вывести числа от 1 до 5. Можно написать пять раз `print`. А если до 1000? Для повторения действий есть **циклы**. Именно циклы позволяют программе за секунду перебрать миллион вариантов, и поэтому они главный инструмент в задачах ЕГЭ.

## 1. Первый цикл

```python
for i in range(5):
    print('Привет')
```

Эта программа выведет `Привет` пять раз. Разберём её:

| Часть | Что это |
|---|---|
| `for` | ключевое слово «для» |
| `i` | **переменная цикла**. На каждом повторе в неё кладётся очередное значение |
| `in range(5)` | «из диапазона 5»: значения 0, 1, 2, 3, 4 |
| `:` | двоеточие, как в `if` |
| `    print(...)` | **тело цикла** с отступом: что повторять |

Один проход тела цикла называется **итерацией** (повтором).

### Переменная цикла меняется

Самое интересное: на каждом повторе `i` принимает **новое** значение.

```python
for i in range(5):
    print(i)
```

```
0
1
2
3
4
```

Что происходит по шагам:

| Итерация | i | Выполняется |
|---|---|---|
| 1 | 0 | `print(0)` |
| 2 | 1 | `print(1)` |
| 3 | 2 | `print(2)` |
| 4 | 3 | `print(3)` |
| 5 | 4 | `print(4)` |

После последнего значения цикл заканчивается, и программа идёт дальше — к первой строке **без отступа** после цикла.

Обрати внимание: `range(5)` — это 0, 1, 2, 3, 4. Счёт начинается **с нуля**, а число 5 **не входит**. Всего значений ровно 5.

## 2. Всё о `range`

![Как работает range](images/range.svg)

У `range` может быть один, два или три числа в скобках:

| Запись | Значения | Пояснение |
|---|---|---|
| `range(5)` | 0, 1, 2, 3, 4 | от 0 до 5, не включая 5 |
| `range(2, 6)` | 2, 3, 4, 5 | от 2 до 6, не включая 6 |
| `range(1, 10, 2)` | 1, 3, 5, 7, 9 | от 1 с шагом 2 |
| `range(10, 0, -1)` | 10, 9, 8, …, 1 | обратный отсчёт, шаг −1 |
| `range(5, 5)` | ничего | пустой диапазон, цикл не выполнится ни разу |

> ⚠️ **Правая граница никогда не входит.** Чтобы перебрать числа от `a` до `b` **включительно**, пиши `range(a, b + 1)`. Забыть `+ 1` — самая частая ошибка с циклами.

```python
n = int(input())
for i in range(1, n + 1):    # от 1 до n включительно
    print(i)
```

## 3. Используем переменную цикла в вычислениях

С переменной цикла можно делать что угодно:

```python

    print(i, i * i)
```

```
1 1
2 4
3 9
4 16

```

## 4. Накопление суммы

Задача: найти сумму чисел от 1 до 5. Нужна переменная, в которой сумма будет **накапливаться**.

```python
s = 0                     # 1. до цикла: сумма пока ноль
for i in range(1, 6):
    s = s + i             # 2. на каждом шаге добавляем очередное число
print(s)                  # 3. после цикла выводим результат
```

Трассировка:

| Итерация | i | s до | s после |
|---|---|---|---|
| 1 | 1 | 0 | 1 |
| 2 | 2 | 1 | 3 |
| 3 | 3 | 3 | 6 |
| 4 | 4 | 6 | 10 |
| 5 | 5 | 10 | 15 |

Выведет `15`.

Три важных момента, которые новички часто путают:

1. `s = 0` стоит **до** цикла. Если поставить его внутрь, сумма будет обнуляться на каждом шаге.
2. `s = s + i` (или короче `s += i`) стоит **внутри** цикла, с отступом.
3. `print(s)` стоит **после** цикла, без отступа. Если сделать отступ, сумма будет выводиться на каждом шаге.

## 5. Шаблоны: сумма, количество, произведение

Почти все задачи на циклы — это один из этих шаблонов:

| Что считаем | Начальное значение | В цикле |
|---|---|---|
| сумму | `s = 0` | `s += x` |
| количество | `cnt = 0` | `cnt += 1` (когда выполнено условие) |
| произведение | `p = 1` | `p *= x` |

Произведение начинают с **единицы**, а не с нуля: если начать с 0, то сколько ни умножай, получится 0.

## 6. Условие внутри цикла

Самое мощное — сочетать цикл и `if`. Сколько чисел от 1 до 100 делятся на 7?

```python
cnt = 0
for x in range(1, 101):
    if x % 7 == 0:
        cnt += 1
print(cnt)    # 14
```

Обрати внимание на отступы: `if` внутри цикла (4 пробела), а `cnt += 1` внутри `if` (8 пробелов).

Так решается огромное количество задач ЕГЭ: «перебери все числа и посчитай подходящие». Например, «сколько чисел от 1 до 10 000 делятся на 7 и не делятся на 3»:

```python
cnt = 0
for n in range(1, 10001):
    if n % 7 == 0 and n % 3 != 0:
        cnt += 1
print(cnt)
```

## 7. Ввод в цикле

Часто в задаче сначала дано количество чисел `n`, а потом сами числа — **каждое на своей строке**:

```
4
10
-3
7
2
```

Читаем первое число, а потом в цикле — остальные:

```python
n = int(input())          # сколько чисел будет дальше
s = 0
for i in range(n):        # повторить n раз
    x = int(input())      # прочитать очередное число
    s += x
print(s)                  # 16
```

Здесь `i` внутри цикла не используется — нам просто нужно повторить чтение `n` раз. Так тоже можно.

## 8. Поиск максимума в цикле

Как в уроке 4, но для многих чисел: сначала считаем максимумом первое число, потом сравниваем с ним все остальные.

```python
n = int(input())
mx = int(input())          # первое число — пока что максимум
for i in range(n - 1):     # остальные n − 1 чисел
    x = int(input())
    if x > mx:
        mx = x
print(mx)
```

## 9. Вложенные циклы

Внутри цикла можно написать ещё один цикл. Внутренний цикл **полностью** проходит для **каждого** шага внешнего:

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(i * j, end=' ')
    print()
```

```
1 2 3
2 4 6
3 6 9
```

Когда `i = 1`, `j` пробегает 1, 2, 3, и выводится первая строка. Затем `print()` переводит строку. Потом `i = 2`, и `j` снова пробегает 1, 2, 3. И так далее.

## Частые ошибки

| Ошибка | Что получится |
|---|---|
| `range(1, n)` вместо `range(1, n + 1)` | последнее число не попадёт в перебор |
| `s = 0` внутри цикла | сумма каждый раз обнуляется |
| `print` с отступом внутри цикла | ответ выводится на каждом шаге, а не один раз |
| забыто двоеточие после `for ... in range(...)` | `SyntaxError: expected ':'` |
| произведение начинается с `p = 0` | ответ всегда 0 |

## Проверь себя

Что выведет программа?

```python
s = 0
for i in range(2, 10, 3):
    s += i
    print(i)
print('s =', s)
```

<details>
<summary>Показать ответ</summary>

```
2
5
8
s = 15
```

`range(2, 10, 3)` — это 2, 5, 8 (следующее было бы 11, но оно больше 10). Сумма 2 + 5 + 8 = 15.

</details>
