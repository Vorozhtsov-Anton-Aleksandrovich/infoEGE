# Урок 10. Работа с файлами

В заданиях 9, 17, 18, 22, 24, 26, 27 данные даются **в файле**: тысячи чисел или строка из миллиона символов. Ввести их руками невозможно, поэтому программа должна сама прочитать файл.

## 1. Где программа ищет файл

![Файл должен лежать рядом с программой](images/file-read.svg)

Если открыть файл просто по имени, например `open('17.txt')`, Python ищет его **в той же папке, где запускается программа**. На этом сайте файл к задаче уже лежит рядом с твоей программой: открывай его по имени из условия.

Как положить файл рядом с программой у себя на компьютере, разберём в уроках про IDLE и PyCharm в конце курса.

## 2. Открыть файл: `open`

```python
f = open('17.txt')
```

`open` («открыть») возвращает **файловый объект**: через него можно читать содержимое. Файл открывается **для чтения**: изменить его так нельзя, и это хорошо — данные не испортятся.

Если файла нет, будет ошибка `FileNotFoundError: [Errno 2] No such file or directory: '17.txt'`. Проверь имя файла (буква в букву, вместе с `.txt`) и то, где он лежит.

## 3. Что такое строки файла

Текстовый файл состоит из **строк**. В конце каждой строки стоит невидимый символ **перевода строки**, в Python он записывается как `'\n'`. Например, файл

```
10
-3
7
```

на самом деле хранится как `'10\n-3\n7\n'`. Это важно: при чтении строки этот `\n` остаётся в её конце, и иногда его нужно убирать.

## 4. Способ 1: одна строка — `readline`

`f.readline()` читает **одну следующую** строку файла. Каждый новый вызов читает следующую строку.

В задании 24 весь файл — это одна длинная строка символов:

```python
s = open('24.txt').readline().strip()
print(len(s))
```

`.strip()` убирает `\n` в конце. Если его забыть, длина строки окажется на 1 больше, а последний «символ» будет переводом строки, и ответ может не сойтись.

## 5. Способ 2: перебрать все строки в цикле

Файловый объект можно перебирать в цикле `for`: на каждом шаге в переменную попадает **очередная строка файла**.

```python
for line in open('17.txt'):
    print(line.strip())
```

Если в каждой строке одно число (задание 17), собираем их в список:

```python
a = []
for line in open('17.txt'):
    a.append(int(line))
```

Короче, генератором списка:

```python
a = [int(line) for line in open('17.txt')]
```

Здесь `.strip()` не обязателен: `int` сам игнорирует `\n` и пробелы по краям. `int('10\n')` даёт 10.

## 6. Способ 3: несколько чисел в строке

В задании 9 в каждой строке файла несколько чисел через пробел или табуляцию. Делаем так же, как с `input()` в уроке 2: разрезаем строку `split()` и превращаем в числа.

```python
for line in open('9.txt'):
    row = list(map(int, line.split()))
    print(row)        # например [12, 5, 40, 7]
```

`split()` без аргументов режет по **любым** пробелам и табуляциям и сам убирает `\n`.

## 7. Способ 4: сначала заголовок, потом данные

В заданиях 26 и 27 первая строка файла — особая, например количество чисел, а дальше идут сами данные:

```
4
80
30
50
40
```

Первую строку читаем отдельно через `readline`, а остальные — в цикле:

```python
f = open('26.txt')
n = int(f.readline())        # первая строка: 4
a = []
for i in range(n):
    a.append(int(f.readline()))
print(a)                     # [80, 30, 50, 40]
```

Важно, что мы работаем с **одной и той же** переменной `f`: каждый `readline` продолжает с того места, где остановился предыдущий.

Если в первой строке два числа, например `100 4`:

```python
f = open('26.txt')
S, N = map(int, f.readline().split())
```

## 8. Конструкция `with`

Так тоже часто пишут:

```python
with open('17.txt') as f:
    a = [int(line) for line in f]
```

`with` автоматически **закроет** файл, когда блок с отступом закончится. Для задач ЕГЭ это не обязательно, но если увидишь такую запись в чужом коде — теперь знаешь, что она значит.

## 9. Таблицы Excel и `.csv`

Если дан файл `.xlsx` (таблица Excel), проще всего открыть его в Excel и сохранить как текст: **Файл → Сохранить как → Текст (разделитель — табуляция) (*.txt)**. Получится обычный текстовый файл, его читаешь как в разделе 6.

Файл `.csv` — это текст, где значения разделены точкой с запятой или запятой. Его читают так же, только режут `split(';')` или `split(',')`.

## 10. Кодировка

Если в файле есть русские буквы, а при чтении появляется `UnicodeDecodeError`, укажи кодировку явно:

```python
open('9.txt', encoding='utf-8')
```

Если и так ошибка, попробуй `encoding='cp1251'`: в этой кодировке часто сохраняет файлы Windows.

## Частые ошибки

| Ошибка | Что не так |
|---|---|
| `FileNotFoundError` | файл не рядом с программой или опечатка в имени |
| длина строки на 1 больше | забыт `.strip()` после `readline()` |
| `ValueError: invalid literal for int()` | в строке несколько чисел или пустая строка — нужен `split()` |
| дважды открыт файл: `open(...).readline()` в цикле | каждый раз читается **первая** строка заново. Открой файл один раз и сохрани в `f` |

## Проверь себя

В файле `data.txt` три строки: `5 2`, `7 1`, `3 9`. Что выведет программа?

```python
s = 0
for line in open('data.txt'):
    a, b = map(int, line.split())
    s += a * b
print(s)
```

<details>
<summary>Показать ответ</summary>

`44` — это 5 · 2 + 7 · 1 + 3 · 9 = 10 + 7 + 27.

</details>
