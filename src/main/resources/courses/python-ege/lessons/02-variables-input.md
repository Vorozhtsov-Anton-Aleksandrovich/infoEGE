# Урок 2. Переменные и ввод данных

В первом уроке программа всегда выводила одно и то же. Настоящие программы работают с **данными**: получают числа, запоминают их, считают. Для этого нужны переменные и ввод.

## 1. Переменная — подписанная коробка

**Переменная** — это место в памяти компьютера, у которого есть **имя** и в котором лежит **значение**. Удобно представлять её как коробку с надписью.

```python
a = 5
```

Эта строка значит: «возьми коробку с надписью `a` и положи в неё число 5». Если коробки `a` ещё не было, Python её создаст.

![Переменные как подписанные коробки](images/variables.svg)

Теперь в любом месте программы можно написать `a`, и Python подставит то, что лежит в коробке:

```python
a = 5
print(a)        # 5
print(a + 10)   # 15
print('a')      # a — в кавычках это просто буква, а не переменная!
```

### Знак `=` — это не «равно»

В математике `a = 5` значит «a равно 5». В Python знак `=` значит **«положить»**: вычислить то, что **справа**, и положить результат в переменную **слева**. Это называется **присваивание**.

Поэтому в Python можно написать строку, которая в математике бессмысленна:

```python
a = 5
a = a + 1
print(a)    # 6
```

Как Python выполняет вторую строку:

1. Смотрит **справа** от `=`: `a + 1`.
2. Достаёт из коробки `a` текущее значение: 5.
3. Считает: 5 + 1 = 6.
4. Кладёт 6 в коробку `a`. **Старое значение 5 пропадает**: в коробке всегда лежит что-то одно.

### Следим за переменными по шагам

Разберём программу построчно. Такая таблица называется **трассировкой**, и она очень помогает понять, что делает программа.

```python
x = 3
y = x * 2
x = x + y
print(x, y)
```

| Строка | Что происходит | x | y |
|---|---|---|---|
| `x = 3` | кладём 3 в x | 3 | — |
| `y = x * 2` | 3 · 2 = 6, кладём в y | 3 | 6 |
| `x = x + y` | 3 + 6 = 9, кладём в x | 9 | 6 |
| `print(x, y)` | выводим | 9 | 6 |

Программа выведет `9 6`.

### Как называть переменные

- Можно латинские буквы, цифры и знак подчёркивания `_`: `a`, `x1`, `total`, `max_sum`.
- Имя **не может начинаться с цифры**: `1x` — ошибка.
- Пробелов в имени быть не может: вместо `my number` пиши `my_number`.
- Большие и маленькие буквы различаются: `count` и `Count` — две разные переменные.
- Нельзя называть переменную словами, которые заняты в Python: `print`, `if`, `for` и т. п.

Старайся давать понятные имена: `price` (цена) понятнее, чем `p`. Но для коротких задач ЕГЭ однобуквенные имена `a`, `b`, `n`, `s` — нормально.

## 2. Сокращённая запись

Увеличить переменную на какое-то число приходится постоянно, поэтому для этого есть короткая запись:

| Коротко | То же самое полностью |
|---|---|
| `x += 3` | `x = x + 3` |
| `x -= 3` | `x = x - 3` |
| `x *= 3` | `x = x * 3` |

```python
s = 10
s += 5      # s = 15
s *= 2      # s = 30
print(s)    # 30
```

## 3. Ввод данных: `input`

Чтобы программа работала с любыми числами, а не только с теми, что записаны в коде, данные нужно **прочитать**. Это делает команда `input()` (по-английски «ввод»).

```python
name = input()
print('Привет,', name)
```

Что происходит:

1. `input()` **останавливает программу и ждёт**, пока пользователь наберёт строку и нажмёт Enter.
2. То, что он набрал, `input()` **возвращает**: как будто на месте `input()` появляется введённый текст.
3. `name = ...` кладёт этот текст в переменную `name`.
4. `print` выводит приветствие.

Если ввести `Аня`, программа выведет `Привет, Аня`.

### Как вводить данные на этом сайте

Под редактором есть поле **«Ввод»**. Всё, что ты в него напишешь, программа получит так, будто это набрали на клавиатуре. **Каждая строка поля — отдельный ввод**: первый `input()` прочитает первую строку, второй `input()` — вторую, и так далее.

При проверке поле «Ввод» не нужно: каждый тест сам подставляет свои данные.

> ⚠️ Не пиши подсказку внутри `input('Введите число: ')`. Эта подсказка выводится на экран, попадает в вывод программы, и тест не пройдёт. Пиши просто `input()`.

### `input()` всегда возвращает текст

Это самая частая ловушка новичков. Даже если пользователь ввёл цифры, `input()` вернёт **текст** из этих цифр:

```python
a = input()    # ввели 2
b = input()    # ввели 3
print(a + b)   # 23 !!!
```

Почему `23`, а не `5`? Потому что `a` — это текст `'2'`, `b` — текст `'3'`. А «сложение» текстов — это склеивание: `'2' + '3'` = `'23'`.

Чтобы получить **число**, текст нужно превратить в число командой `int()` (от английского integer — целое число):

```python
a = int(input())   # ввели 2 → a = 2 (число)
b = int(input())   # ввели 3 → b = 3 (число)
print(a + b)       # 5
```

Запись `int(input())` читается изнутри наружу: сначала `input()` получает текст `'2'`, потом `int(...)` превращает его в число 2.

Если ввести не число, а, например, `abc`, команда `int` не сможет его превратить, и будет ошибка `ValueError: invalid literal for int() with base 10: 'abc'`.

## 4. Типы данных

У каждого значения в Python есть **тип**: что это за данные.

| Тип | Примеры | Что это |
|---|---|---|
| `int` | `42`, `-7`, `0`, `10**100` | целое число |
| `float` | `3.14`, `2.0`, `-0.5` | дробное число |
| `str` | `'abc'`, `'10'`, `''` | строка (текст) |

`'10'` (строка) и `10` (число) выглядят похоже, но ведут себя по-разному:

```python
print('10' + '5')   # 105 — склеились строки
print(10 + 5)       # 15  — сложились числа
print('10' * 3)     # 101010 — строка повторилась 3 раза
print(10 * 3)       # 30
```

Превращать одно в другое можно так:

| Запись | Результат |
|---|---|
| `int('17')` | `17` — строку в целое число |
| `float('2.5')` | `2.5` — строку в дробное |
| `str(17)` | `'17'` — число в строку |
| `int(3.9)` | `3` — дробная часть отбрасывается |

## 5. Подробнее о `print`

Ты уже знаешь, что `print` выводит значения через пробел. Это можно изменить:

```python
print(1, 2, 3)              # 1 2 3
print(1, 2, 3, sep='')      # 123     — sep: чем разделять
print(1, 2, 3, sep=', ')    # 1, 2, 3
print(1, 2, 3, sep='\n')    # каждое число на новой строке
```

`sep` (от separator — разделитель) задаёт, что ставить **между** значениями. `'\n'` — это специальный символ «перевод строки».

Ещё `print` после вывода всегда переходит на новую строку. Это меняется параметром `end` (что ставить в конце):

```python
print('Привет', end=' ')
print('мир')
```

```
Привет мир
```

## 6. Несколько чисел в одной строке

Часто в задаче числа даны **в одной строке через пробел**, например `3 8`. Одного `int(input())` тут мало: `int('3 8')` выдаст ошибку, потому что `'3 8'` — не одно число.

Решение, которое нужно просто запомнить:

```python
a, b = map(int, input().split())
print(a + b)    # ввод 3 8 → 11
```

Разберём по шагам, что происходит при вводе `3 8`:

| Шаг | Запись | Результат |
|---|---|---|
| 1 | `input()` | строка `'3 8'` |
| 2 | `.split()` | разрезает по пробелам: `['3', '8']` (список из двух строк) |
| 3 | `map(int, ...)` | применяет `int` к каждой: `3` и `8` |
| 4 | `a, b = ...` | первое число кладёт в `a`, второе — в `b` |

Если чисел три, пиши три переменные: `a, b, c = map(int, input().split())`. Количество переменных слева должно **совпадать** с количеством чисел, иначе будет ошибка `ValueError: too many values to unpack` (слишком много значений) или `not enough values to unpack` (не хватает).

Запомни разницу:

- числа **на разных строках** → несколько раз `int(input())`;
- числа **в одной строке** → один раз `map(int, input().split())`.

## 7. Обмен значений

Как поменять местами значения двух переменных? Неправильно так:

```python
a = 1
b = 2
a = b    # a = 2, а старое значение 1 пропало навсегда
b = a    # b = 2
print(a, b)   # 2 2 — не то!
```

В Python есть удобная запись, которая делает обмен за одну строку:

```python
a, b = b, a
```

Python сначала вычисляет всё справа (`2, 1`), а потом раскладывает по переменным слева.
