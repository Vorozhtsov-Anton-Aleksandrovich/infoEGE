# Урок 12. Python на своём компьютере: установка и IDLE

Всё это время ты писал программы на сайте. Но на экзамене сайта не будет: на компьютере в пункте сдачи (станции КЕГЭ) установлены **Python и IDLE**, а часто ещё **PyCharm** или Wing IDE. Поэтому важно уметь работать с ними. В этом уроке поставим Python к себе на компьютер и разберёмся с IDLE — средой, которая идёт вместе с Python.

Сами программы пишутся точно так же, как на сайте. Меняется только место, где ты их набираешь и запускаешь.

## 1. Скачиваем Python

1. Открой в браузере сайт **python.org**.
2. Наведи мышь на раздел **Downloads** (Загрузки) в верхнем меню.
3. Нажми жёлтую кнопку **Download Python 3.x.x**. Сайт сам определит твою систему (Windows или macOS). Бери последнюю версию, она начинается с 3.12 или выше.
4. Дождись, пока файл скачается (обычно он попадает в папку «Загрузки»), и запусти его двойным щелчком.

## 2. Устанавливаем

Откроется окно установщика.

![Установщик Python: галочка Add python.exe to PATH](images/python-installer.svg)

> ⚠️ **Самое важное во всём уроке:** внизу первого окна поставь галочку **«Add python.exe to PATH»**. Без неё Python не будет запускаться из командной строки, и PyCharm может его не найти. Это самая частая проблема при установке.

5. Поставив галочку, нажми **Install Now** (Установить сейчас).
6. Если Windows спросит «Разрешить этому приложению вносить изменения?», нажми **Да**.
7. Подожди минуту-две. Когда появится надпись **Setup was successful** (установка прошла успешно), нажми **Close**.

На macOS установщик выглядит по-другому, но там достаточно нажимать **Continue** (Продолжить) и **Install**. Галочки PATH на Mac нет, она не нужна.

## 3. Проверяем, что всё получилось

На Windows:

1. Нажми на клавиатуре **Win + R** (клавиша с флажком Windows и одновременно R).
2. В появившемся окошке набери `cmd` и нажми Enter. Откроется чёрное окно — **командная строка**.
3. Набери в нём и нажми Enter:

```
python --version
```

Должно появиться что-то вроде `Python 3.13.0`. Значит, всё установлено.

Если вместо этого написано «"python" не является внутренней или внешней командой», значит, при установке не поставили галочку PATH. Исправить просто:

1. Снова запусти скачанный установщик.
2. Выбери **Modify** (Изменить) → **Next** (Далее).
3. Поставь галочку **Add Python to environment variables**.
4. Нажми **Install**, а после установки закрой и заново открой командную строку.

На macOS открой программу **Терминал** и набери `python3 --version` (на Mac пишут `python3`, а не `python`).

## 4. Что такое IDLE

**IDLE** — простая программа для написания кода на Python. Она устанавливается вместе с Python автоматически, ничего отдельно скачивать не нужно.

Найди её: **Пуск** → начни набирать `IDLE` → выбери **IDLE (Python 3.x)**. На Mac она лежит в папке **Программы → Python 3.x**.

У IDLE **два разных окна**, и их важно не путать:

| Окно | Как узнать | Для чего |
|---|---|---|
| **Shell** (оболочка) | в начале строки стоит `>>>` | выполнить одну команду и сразу увидеть результат |
| **Editor** (редактор) | пустой лист, в заголовке имя файла | написать программу целиком, сохранить и запустить |

Когда ты открываешь IDLE, сначала появляется окно **Shell**.

## 5. Shell: Python как калькулятор

![Окно IDLE Shell](images/idle-shell.svg)

После значка `>>>` набери команду и нажми Enter — результат появится на следующей строке:

```python
>>> 2 + 3 * 4
14
>>> 2 ** 10
1024
>>> 17 // 5
3
>>> 17 % 5
2
>>> len('информатика')
11
```

Заметь: здесь не нужен `print` — Shell сам показывает результат каждой команды.

Shell удобен, чтобы быстро что-то проверить или посчитать. Но **писать программу в нём не надо**: каждая строка выполняется сразу, программу нельзя сохранить, а исправить строку, которая выше, нельзя.

Полезные клавиши в Shell:

- **Alt + P** — вставить предыдущую команду (чтобы не набирать заново), **Alt + N** — следующую;
- **Ctrl + C** — остановить команду, которая выполняется слишком долго.

## 6. Editor: пишем настоящую программу

Пошагово:

1. В окне Shell открой меню **File → New File** (или нажми **Ctrl + N**). Откроется новое пустое окно — это **редактор**.
2. Напиши в нём программу:

```python
name = input()
print('Привет,', name)
```

3. **Сохрани** файл: **File → Save** (или **Ctrl + S**). Выбери папку (например, создай на рабочем столе папку `ege`) и назови файл, например, `hello.py`. Окончание `.py` обязательно: по нему компьютер понимает, что это программа на Python.
4. **Запусти** программу: меню **Run → Run Module** или клавиша **F5**.

![Окно редактора IDLE и меню Run](images/idle-editor.svg)

Программа выполнится **в окне Shell**: переключись на него. Программа ждёт ввода — набери имя прямо в Shell и нажми Enter. Там же появится результат.

Если забыть сохранить файл, IDLE при нажатии F5 сам предложит сделать это: нажми **OK**.

### Как исправить и запустить снова

Возвращайся в окно **редактора**, исправляй код и снова нажимай **F5**. IDLE сохранит изменения и перезапустит программу. Каждый новый запуск начинается в Shell со строки `= RESTART =`.

### Ввод данных в IDLE

На сайте данные вводились в поле «Ввод» заранее. В IDLE программа **останавливается** на каждом `input()` и ждёт, пока ты наберёшь строку в Shell и нажмёшь Enter. Если `input()` три, придётся три раза набрать данные и нажать Enter.

## 7. Горячие клавиши IDLE

| Клавиши | Действие |
|---|---|
| `F5` | сохранить и запустить программу |
| `Ctrl + N` | новый файл |
| `Ctrl + O` | открыть файл |
| `Ctrl + S` | сохранить |
| `Ctrl + Z` | отменить последнее действие |
| `Ctrl + ]` / `Ctrl + [` | сдвинуть выделенные строки вправо / влево (поменять отступ) |
| `Alt + 3` / `Alt + 4` | закомментировать / раскомментировать выделенные строки |
| `Alt + P` (в Shell) | предыдущая команда |
| `Ctrl + C` (в Shell) | остановить зависшую программу |

## 8. Если программа зависла

Если программа долго не заканчивается (например, бесконечный цикл `while`), переключись в окно **Shell** и нажми **Ctrl + C**. Появится сообщение `KeyboardInterrupt` — программа остановлена. Если не помогло, закрой окно Shell: IDLE спросит, остановить ли программу, — соглашайся.

## 9. Ошибки в IDLE

Ошибки выглядят так же, как на сайте, только выводятся красным в Shell:

```
Traceback (most recent call last):
  File "C:\Users\Аня\Desktop\ege\hello.py", line 2, in <module>
    print('Привет', nme)
NameError: name 'nme' is not defined
```

Читай как раньше: **последняя строка** — что за ошибка, строка с `line 2` — где. Здесь в строке 2 опечатка: `nme` вместо `name`.

Ошибки синтаксиса (`SyntaxError`) IDLE показывает ещё до запуска: появляется окошко с сообщением, а место ошибки в редакторе подсвечивается красным.

## 10. Файлы к заданиям

В заданиях с файлами (9, 17, 24, 26, 27) программа открывает файл по имени: `open('17.txt')`. Чтобы это сработало, **файл должен лежать в той же папке, где сохранена программа**.

Порядок действий на экзамене:

1. Найди файл к заданию (например, `17.txt`) и посмотри, в какой он папке.
2. Сохрани свою программу **в ту же папку**: **File → Save As** и выбери эту папку.
3. Запускай через **F5**.

Если всё равно появляется `FileNotFoundError`, можно указать **полный путь** к файлу:

```python
a = [int(x) for x in open(r'C:\Users\Аня\Desktop\ege\17.txt')]
```

Буква `r` перед кавычкой нужна из-за обратных косых черт `\` в пути. Полный путь можно скопировать из адресной строки Проводника.

## Практика

Задачи ниже реши **сначала в IDLE** у себя на компьютере: создай файл, напиши программу, запусти через F5 и проверь на примере. А потом скопируй код в редактор на сайте и нажми «Проверить».
