# Урок 7. Списки

Список — это много значений под одним именем. Нужен в заданиях 17, 25, 26, 27 и везде, где данные приходят «пачкой».

## 1. Создание и индексы

```python
a = [5, 8, 2, 9]
print(a[0])     # 5
print(a[-1])    # 9
print(len(a))   # 4
a[1] = 100      # список МОЖНО менять: [5, 100, 2, 9]
```

![Индексы списка](images/list-index.svg)

Срезы работают как у строк: `a[1:3]`, `a[::-1]`.

## 2. Добавление и удаление

```python
a = []
a.append(3)     # [3]
a.append(7)     # [3, 7]
a.insert(0, 1)  # [1, 3, 7]
a.pop()         # убрать последний → [1, 3]
a.remove(1)     # убрать первое значение 1 → [3]
```

## 3. Чтение списка чисел

Все в одной строке:

```python
a = list(map(int, input().split()))
```

Сначала `n`, потом `n` строк по одному числу:

```python
n = int(input())
a = [int(input()) for i in range(n)]
```

Последняя запись — **генератор списка**. Общий вид: `[выражение for x in что-то if условие]`.

```python
squares = [x * x for x in range(1, 6)]       # [1, 4, 9, 16, 25]
evens = [x for x in a if x % 2 == 0]          # только чётные из a
```

## 4. Встроенные функции

| Функция | Что даёт |
|---|---|
| `sum(a)` | сумму |
| `max(a)`, `min(a)` | максимум, минимум |
| `len(a)` | количество |
| `sorted(a)` | новый отсортированный список |
| `sorted(a, reverse=True)` | по убыванию |
| `a.sort()` | сортирует сам список |
| `a.count(x)` | сколько раз `x` в списке |
| `x in a` | есть ли `x` |

## 5. Перебор

```python
for x in a:              # по значениям
    print(x)

for i in range(len(a)):  # по индексам — когда нужен сосед a[i+1]
    print(i, a[i])
```

## 6. Пары соседних элементов (задание 17)

«Найдите количество пар **соседних** элементов, в которых хотя бы одно число делится на 3»:

```python
cnt = 0
for i in range(len(a) - 1):
    if a[i] % 3 == 0 or a[i + 1] % 3 == 0:
        cnt += 1
```

`range(len(a) - 1)` — потому что у последнего элемента нет правого соседа, и `a[i + 1]` вылетел бы за границу (`IndexError`).

## 7. Множество `set` — только уникальные значения

```python
a = [3, 1, 3, 2, 1]
print(len(set(a)))    # 3 — различных значений
print(sorted(set(a))) # [1, 2, 3]
```
