# Урок 13. PyCharm и отладчик

IDLE простой, но для длинных программ неудобен. **PyCharm** — профессиональная среда для Python. Она подсказывает код, подчёркивает ошибки ещё **до запуска** и, главное, умеет выполнять программу **по шагам** и показывать значения всех переменных. Это очень помогает понять, почему программа выдаёт не тот ответ.

На многих станциях КЕГЭ PyCharm тоже установлен. Но даже если на экзамене будет только IDLE, дома готовиться в PyCharm удобнее.

С 2025 года PyCharm — один продукт: первый месяц открыты все платные функции, а потом основные функции остаются **бесплатными**. Для ЕГЭ бесплатной части хватает с запасом.

## 1. Установка

1. Сначала установи **Python** (урок 12). PyCharm сам Python не ставит, а использует уже установленный.
2. Открой сайт **jetbrains.com/pycharm/download** и скачай установщик для своей системы.
3. Запусти установщик и нажимай **Next**. На экране **Installation Options** (параметры установки) отметь:
   - **Create Desktop Shortcut** — значок на рабочем столе;
   - **Add "Open Folder as Project"** — открывать папки как проекты;
   - **.py** — открывать файлы `.py` в PyCharm.
4. Нажми **Install**, дождись окончания и запусти PyCharm.
5. При первом запуске PyCharm может спросить про настройки и тему оформления — можно ничего не менять и нажать **Next** или **Skip**.

> Если сайт JetBrains не открывается, попроси преподавателя скинуть установщик. Пока PyCharm нет, решай в IDLE: для задач разницы нет.

## 2. Проект — это папка

PyCharm работает с **проектами**. Проект — это просто папка, в которой лежат твои программы и файлы к задачам. Удобно завести один проект `ege` для всей подготовки.

1. На стартовом экране нажми **New Project** (Новый проект).
2. **Name** (Имя): `ege` — так будет называться папка проекта.
3. **Location** (Расположение): где будет лежать папка, например `C:\Users\Имя\PycharmProjects`. Можно оставить как есть.
4. **Interpreter type** (тип интерпретатора): оставь **Project venv**. В поле **Python version** должна стоять твоя версия Python, например `Python 3.13`.
5. Галочку **Create a welcome script** (создать приветственный файл) можно снять.
6. Нажми **Create** (Создать).

![Окно New Project в PyCharm](images/pycharm-new-project.svg)

Если в поле Python version пусто или написано *No interpreter*, значит, Python не установлен или установлен без галочки PATH. Вернись к уроку 12.

При первом открытии проекта PyCharm может несколько минут «индексировать» файлы: внизу окна бежит полоска. Подожди, пока она закончится.

## 3. Как устроено окно

| Часть окна | Где | Для чего |
|---|---|---|
| **Project** | слева | дерево файлов проекта |
| **Редактор** | в центре | здесь пишешь код |
| **Run** | внизу, появляется после запуска | вывод программы и ввод данных |
| кнопки ▶ и 🐞 | сверху справа | запуск и запуск с отладчиком |

## 4. Создаём файл и запускаем

1. В панели **Project** слева нажми **правой кнопкой мыши** по папке `ege` → **New** → **Python File**.
2. Введи имя файла, например `task5`, и нажми Enter. Окончание `.py` PyCharm допишет сам.
3. Напиши код:

```python
n = int(input())
for i in range(1, n + 1):
    print(i, i * i)
```

4. Запусти одним из способов:
   - правой кнопкой мыши по коду → **Run 'task5'**;
   - зелёный треугольник ▶ сверху справа;
   - клавиши **Ctrl + Shift + F10** (запустить текущий файл).

![Запуск в PyCharm и окно Run](images/pycharm-run.svg)

Внизу откроется окно **Run**. Программа ждёт ввода: **щёлкни мышью в окно Run**, набери число и нажми Enter. Там же появится вывод.

Повторить последний запуск — **Shift + F10**. Остановить программу — красный квадрат ■ в окне Run (или **Ctrl + F2**).

Сохранять файл вручную не нужно: PyCharm сохраняет всё сам.

> ⚠️ Кнопка ▶ сверху запускает **последний** запущенный файл, а не тот, что открыт сейчас. Если у тебя несколько файлов, запускай нужный через правую кнопку → **Run** или **Ctrl + Shift + F10**.

## 5. Подсказки и подсветка ошибок

PyCharm проверяет код, пока ты его пишешь:

- **красная волнистая линия** — ошибка, программа не запустится. Наведи на неё мышь, и появится объяснение;
- **жёлтая или серая подсветка** — предупреждение, например переменная не используется. Программа запустится;
- начни писать `pri` — PyCharm предложит `print`. Нажми **Tab** или **Enter**, чтобы согласиться;
- после `:` и Enter отступ ставится автоматически, как в IDLE.

## 6. Отладчик — смотрим, как работает программа

**Отладчик** (debugger) позволяет выполнять программу **по одной строке** и после каждого шага видеть значения всех переменных. Это та же трассировка, которую мы делали в таблицах, только её делает компьютер. Это главная причина пользоваться PyCharm при подготовке.

Попробуй на этой программе:

```python
s = 0
for i in range(1, 6):
    s += i
print(s)
```

1. **Поставь точку останова.** Щёлкни мышью слева от номера строки `s += i` (на сером поле). Появится красная точка — **breakpoint**. Программа остановится, когда дойдёт до этой строки.
2. **Запусти в режиме отладки.** Нажми на **жука** 🐞 (**Debug**) вместо треугольника, или **Shift + F9**.
3. Программа остановится на строке с точкой, строка подсветится синим. Внизу откроется панель **Debug**, а в ней — список **переменных и их значений**: `i = 1`, `s = 0`.
4. Нажми **F8** (*Step Over*, «шаг»). Выполнится одна строка, и значения обновятся: `s = 1`.
5. Нажимай **F8** дальше и смотри, как меняются `i` и `s` на каждом шаге цикла.
6. **F9** (*Resume*, «продолжить») — выполнять дальше до следующей остановки на точке.
7. Чтобы убрать точку останова, щёлкни по красной точке ещё раз.

![Отладчик PyCharm: точка останова и переменные](images/pycharm-debug.svg)

Так ты увидишь, на каком шаге переменная получила неправильное значение, и поймёшь, где ошибка в логике.

| Клавиша в отладчике | Что делает |
|---|---|
| `F8` | выполнить одну строку |
| `F7` | шаг **внутрь** функции, если в строке её вызов |
| `F9` | продолжить до следующей точки останова |
| `Ctrl + F2` | остановить отладку |

## 7. Горячие клавиши PyCharm

| Клавиши | Действие |
|---|---|
| `Ctrl + Shift + F10` | запустить текущий файл |
| `Shift + F10` | повторить последний запуск |
| `Shift + F9` | запустить в отладчике |
| `Ctrl + /` | закомментировать строку или выделение |
| `Ctrl + D` | скопировать строку ниже |
| `Tab` / `Shift + Tab` | сдвинуть выделенные строки вправо / влево |
| `Ctrl + Alt + L` | аккуратно отформатировать код |
| `Shift + F6` | переименовать переменную во всей программе |
| `Ctrl + Z` | отменить |

## 8. Файлы к заданиям в PyCharm

Программа открывает файл по имени, например `open('17.txt')`, а ищет его **в папке проекта**. Поэтому файл нужно положить туда:

1. Найди файл к заданию в Проводнике.
2. **Перетащи его мышкой** в панель **Project** слева, прямо на папку `ege`.
3. PyCharm спросит, скопировать ли файл, — нажми **OK** или **Refactor**.

Теперь файл виден в дереве проекта рядом с программой, и `open('17.txt')` его найдёт. Двойной щелчок по файлу в панели Project откроет его прямо в PyCharm, чтобы посмотреть, как он устроен.

## IDLE или PyCharm на экзамене?

Без разницы: код одинаковый. На экзамене открывай то, что установлено и к чему привык. Главное — уметь:

1. создать файл с программой;
2. положить рядом файл с данными;
3. запустить программу и найти, где она выводит результат.

## Практика

Задачи ниже — с ошибками в начальном коде. Скопируй код в PyCharm, поставь точку останова внутри цикла и пройди программу по шагам через **F8**. Найди, на каком шаге значение переменной становится неправильным, исправь ошибку и проверь решение здесь, на сайте.
