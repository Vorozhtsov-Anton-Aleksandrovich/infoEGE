# Урок 4. Условия: if, elif, else

## 1. Сравнения

| Запись | Значит |
|---|---|
| `a == b` | равно (два знака!) |
| `a != b` | не равно |
| `a < b`, `a > b` | меньше, больше |
| `a <= b`, `a >= b` | не больше, не меньше |

Результат сравнения — `True` или `False`.

## 2. Ветвление

```python
n = int(input())
if n > 0:
    print('положительное')
elif n < 0:
    print('отрицательное')
else:
    print('ноль')
```

![Схема ветвления if / elif / else](images/if-flow.svg)

Важно:

- после условия стоит **двоеточие** `:`;
- тело условия сдвинуто на **4 пробела** (в IDLE и PyCharm отступ ставится сам после Enter);
- `elif` проверяется, только если все условия выше были ложны;
- `else` — «во всех остальных случаях», условия у него нет.

## 3. Логические операции

| Операция | Значит | Пример |
|---|---|---|
| `and` | И — оба истинны | `x > 0 and x < 10` |
| `or` | ИЛИ — хотя бы одно | `x == 1 or x == 2` |
| `not` | НЕ | `not (x > 5)` |

Python умеет двойные сравнения: `0 < x < 10`.

Это прямо задание 2 ЕГЭ: логическую функцию можно записать на Python. Импликацию `A → B` записывают как `(not A) or B` или `A <= B`, эквивалентность `A ≡ B` — как `A == B`.

```python
x, y = 1, 0
F = (not x or y) and (x == y)
print(int(F))   # 0
```

## 4. Вложенные условия

```python
a, b = map(int, input().split())
if a == b:
    print('равны')
else:
    if a > b:
        print(a)
    else:
        print(b)
```

## 5. Полезные встроенные функции

- `max(a, b, c)`, `min(a, b, c)` — максимум и минимум;
- `abs(x)` — модуль числа.

## Частые ошибки

- `if x = 5:` → `SyntaxError`. Нужно `==`.
- Забыл двоеточие → `SyntaxError: expected ':'`.
- `if x > 0 and < 10` → нельзя, нужно `x > 0 and x < 10`.
