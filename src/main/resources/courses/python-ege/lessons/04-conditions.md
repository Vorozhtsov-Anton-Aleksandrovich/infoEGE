# Урок 4. Условия: if, elif, else

До сих пор программа выполняла все строки подряд. Но часто нужно поступать **по-разному** в зависимости от данных: если число чётное — одно, если нечётное — другое. Для этого есть **условный оператор** `if` (по-английски «если»).

## 1. Сравнения

Условие — это вопрос, на который можно ответить «да» или «нет». В Python ответ «да» — это `True`, «нет» — `False`.

| Запись | Читается | Пример | Результат |
|---|---|---|---|
| `a == b` | a равно b | `5 == 5` | `True` |
| `a != b` | a не равно b | `5 != 3` | `True` |
| `a < b` | a меньше b | `2 < 1` | `False` |
| `a > b` | a больше b | `2 > 1` | `True` |
| `a <= b` | a меньше или равно b | `3 <= 3` | `True` |
| `a >= b` | a больше или равно b | `2 >= 3` | `False` |

> ⚠️ Сравнение «равно» — это **два** знака `==`. Один знак `=` — это «положить в переменную». Перепутать их — самая частая ошибка в условиях.

## 2. Оператор `if`

```python
n = int(input())
if n > 0:
    print('положительное')
print('конец')
```

Как это читать: «**если** n больше нуля, **то** выведи "положительное"». Строка `print('конец')` выполнится в любом случае.

Разберём, из чего состоит `if`:

| Часть | Что это |
|---|---|
| `if` | ключевое слово «если» |
| `n > 0` | условие |
| `:` | **двоеточие** — обязательно! Оно значит «дальше идёт, что делать» |
| `    print(...)` | **тело** условия: команды, которые выполнятся, только если условие истинно |

### Отступы — это важно

Тело условия пишется **с отступом в 4 пробела** от `if`. Именно по отступу Python понимает, какие строки относятся к условию, а какие — нет.

```python
n = 5
if n > 10:
    print('большое')       # в теле if — не выполнится, ведь 5 > 10 ложно
    print('очень большое') # тоже в теле if — тоже не выполнится
print('готово')            # без отступа — выполнится всегда
```

Вывод: `готово`.

В редакторе отступ ставится сам, когда нажимаешь Enter после двоеточия. Чтобы убрать отступ, нажми Backspace. Клавиша Tab тоже ставит отступ.

Все строки одного тела должны иметь **одинаковый** отступ. Если в одной строке 4 пробела, а в другой 3, будет ошибка `IndentationError` («ошибка отступа»).

## 3. `else` — «иначе»

Часто нужно сделать одно, если условие истинно, и **другое** — если ложно:

```python
n = int(input())
if n % 2 == 0:
    print('чётное')
else:
    print('нечётное')
```

`else` («иначе») не имеет своего условия: оно срабатывает **во всех остальных случаях**. После `else` тоже ставится двоеточие, а тело — с отступом. Выполнится **ровно одна** из двух веток.

## 4. `elif` — «а иначе если»

Когда вариантов больше двух, используют `elif` (сокращение от else if):

```python
n = int(input())
if n > 0:
    print('положительное')
elif n < 0:
    print('отрицательное')
else:
    print('ноль')
```

![Схема ветвления if / elif / else](images/if-flow.svg)

Python проверяет условия **по очереди сверху вниз** и выполняет **первую** ветку, условие которой истинно. Остальные пропускает, даже если их условия тоже истинны. Если не подошло ни одно условие, выполняется `else` (если он есть).

Пример: что выведет программа при `n = 15`?

```python
if n > 10:
    print('больше 10')
elif n > 5:
    print('больше 5')
else:
    print('маленькое')
```

Ответ: только `больше 10`. Условие `n > 5` тоже истинно, но до него дело не дошло: первая подходящая ветка уже выполнилась.

## 5. Логические операции: `and`, `or`, `not`

Чтобы объединить несколько условий, используют логические операции:

| Операция | Значит | Истинно, когда | Пример |
|---|---|---|---|
| `and` | И | **оба** условия истинны | `x > 0 and x < 10` |
| `or` | ИЛИ | **хотя бы одно** истинно | `x == 1 or x == 2` |
| `not` | НЕ | условие **ложно** | `not x > 5` |

```python
age = 15
print(age >= 14 and age <= 17)   # True — оба верны
print(age < 7 or age > 60)       # False — оба неверны
print(not age > 18)              # True — age > 18 ложно, а not делает его истинным
```

Python умеет двойные сравнения, как в математике: `0 < x < 10` — то же, что `x > 0 and x < 10`.

Если в условии есть и `and`, и `or`, сначала выполняется `and`. Чтобы не ошибиться, **ставь скобки**:

```python
if (y % 4 == 0 and y % 100 != 0) or y % 400 == 0:
    print('високосный')
```

### Типичная ошибка

```python
if x > 0 and < 10:     # ОШИБКА
if x > 0 and x < 10:   # правильно: x нужно написать дважды
```

```python
if x == 1 or 2:        # ОШИБКА по смыслу: это всегда истинно
if x == 1 or x == 2:   # правильно
```

## 6. Вложенные условия

Внутри одной ветки можно написать ещё одно условие. Его тело сдвигается ещё на 4 пробела:

```python
a, b = map(int, input().split())
if a == b:
    print('равны')
else:
    if a > b:
        print(a)
    else:
        print(b)
```

Вложенные условия можно заменить на `elif`, и часто так получается проще.

## 7. Поиск максимума

Как найти наибольшее из трёх чисел без готовой функции? Классический приём: **предположим, что максимум — первое число, а потом проверим остальные**.

```python
a, b, c = map(int, input().split())
m = a          # пока что считаем, что больше всех a
if b > m:      # если b больше — теперь максимум b
    m = b
if c > m:      # если c больше текущего максимума — теперь c
    m = c
print(m)
```

Трассировка для ввода `4 9 7`:

| Строка | m |
|---|---|
| `m = a` | 4 |
| `if b > m` → 9 > 4, да → `m = b` | 9 |
| `if c > m` → 7 > 9, нет | 9 |

Выведет `9`. Этот приём понадобится ещё много раз.

В Python есть и готовые функции: `max(a, b, c)` — наибольшее, `min(a, b, c)` — наименьшее, `abs(x)` — модуль числа.

## 8. Логика и задание 2 ЕГЭ

В задании 2 даны логические выражения со значками `∧` (и), `∨` (или), `¬` (не), `→` (импликация, «следует»), `≡` (эквивалентность). Их можно записать на Python, считая, что 1 — это истина, 0 — ложь:

| Значок | На Python |
|---|---|
| `A ∧ B` | `A and B` |
| `A ∨ B` | `A or B` |
| `¬A` | `not A` |
| `A → B` | `(not A) or B` |
| `A ≡ B` | `A == B` |

Импликация `A → B` ложна только в одном случае: когда A истинно, а B ложно. Поэтому её записывают как `(not A) or B`.

```python
x, y = 1, 0
F = (not x or y) and (x == y)
print(int(F))   # 0
```

`int(F)` превращает `True` в 1, а `False` в 0.

## Частые ошибки

| Ошибка | Что не так |
|---|---|
| `if x = 5:` | нужно `==` |
| `if x > 5` без двоеточия | `SyntaxError: expected ':'` |
| тело без отступа | `IndentationError: expected an indented block` |
| `else x < 0:` | у `else` нет условия, нужно `elif x < 0:` |
| `Print('да')` | команды пишутся маленькими буквами |

## Проверь себя

Что выведет программа при `n = 7`?

```python
if n % 2 == 0:
    print('A')

    print('B')
elif n > 3:
    print('C')
else:
    print('D')
print('E')
```
