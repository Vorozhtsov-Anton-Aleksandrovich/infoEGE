# Урок 8. Списки

Представь, что нужно сохранить оценки 30 учеников. Заводить 30 переменных `a1`, `a2`, …, `a30` неудобно. Для этого есть **список** — много значений под одним именем. Списки нужны в заданиях 17, 25, 26, 27 и везде, где данные приходят «пачкой».

## 1. Как создать список

Список записывается в **квадратных скобках**, элементы — через запятую:

```python
a = [5, 8, 2, 9]
names = ['Аня', 'Петя', 'Оля']
empty = []           # пустой список
print(a)             # [5, 8, 2, 9]
```

## 2. Индексы — как у строк

![Индексы списка](images/list-index.svg)

У каждого элемента есть номер, и он тоже начинается **с нуля**:

```python
a = [5, 8, 2, 9]
print(a[0])     # 5 — первый элемент
print(a[3])     # 9 — четвёртый
print(a[-1])    # 9 — последний
print(len(a))   # 4 — количество элементов
```

Срезы работают точно так же, как у строк: `a[1:3]` → `[8, 2]`, `a[::-1]` → `[9, 2, 8, 5]`.

### Главное отличие от строк: список можно менять

```python
a = [5, 8, 2, 9]
a[1] = 100
print(a)    # [5, 100, 2, 9]
```

## 3. Добавление и удаление

| Команда | Что делает | Список после |
|---|---|---|
| `a = []` | пустой список | `[]` |
| `a.append(3)` | добавить 3 **в конец** | `[3]` |
| `a.append(7)` | добавить 7 в конец | `[3, 7]` |
| `a.insert(0, 1)` | вставить 1 на место с индексом 0 | `[1, 3, 7]` |
| `a.pop()` | убрать последний элемент | `[1, 3]` |
| `a.remove(1)` | убрать первый элемент, равный 1 | `[3]` |

Чаще всего нужен `append`: создаём пустой список и в цикле добавляем в него подходящие значения.

```python
evens = []
for x in range(1, 11):
    if x % 2 == 0:
        evens.append(x)
print(evens)    # [2, 4, 6, 8, 10]
```

## 4. Перебор списка

Как и строку, список можно перебирать двумя способами.

**По значениям** — когда нужны только сами элементы:

```python
a = [5, 8, 2, 9]
for x in a:
    print(x * 10)
```

**По индексам** — когда нужен номер или соседний элемент:

```python
for i in range(len(a)):
    print('элемент номер', i, 'равен', a[i])
```

## 5. Чтение списка чисел

Это нужно почти в каждой задаче, запомни оба способа.

**Все числа в одной строке** через пробел (`3 9 -2 5`):

```python
a = list(map(int, input().split()))
```

Это как в уроке 2, только вместо `a, b = ...` мы собираем **все** числа в список командой `list(...)`. Сколько чисел ввели — столько и будет в списке.

**Сначала количество `n`, потом `n` чисел**, каждое на своей строке:

```python
n = int(input())
a = []
for i in range(n):
    a.append(int(input()))
```

То же самое короче:

```python
n = int(input())
a = [int(input()) for i in range(n)]
```

## 6. Генератор списка

Последняя запись — это **генератор списка**: способ создать список одной строкой. Общий вид:

```
[выражение for переменная in что-перебирать if условие]
```

Часть с `if` необязательна.

```python
squares = [x * x for x in range(1, 6)]     # [1, 4, 9, 16, 25]
evens = [x for x in range(1, 11) if x % 2 == 0]   # [2, 4, 6, 8, 10]
a = [5, -3, 8, -1]
pos = [x for x in a if x > 0]               # [5, 8]
```

Читать так: «список из `x * x` для каждого `x` из `range(1, 6)`». Если генератор кажется сложным, всегда можно написать обычный цикл с `append` — результат одинаковый.

## 7. Готовые функции для списков

| Функция | Что даёт | Для `a = [5, 8, 2, 8]` |
|---|---|---|
| `len(a)` | количество элементов | `4` |
| `sum(a)` | сумма | `23` |
| `max(a)` | наибольший | `8` |
| `min(a)` | наименьший | `2` |
| `sorted(a)` | **новый** отсортированный список | `[2, 5, 8, 8]` |
| `sorted(a, reverse=True)` | по убыванию | `[8, 8, 5, 2]` |
| `a.sort()` | сортирует **сам** список `a` | `a` станет `[2, 5, 8, 8]` |
| `a.count(8)` | сколько раз встречается 8 | `2` |
| `8 in a` | есть ли 8 в списке | `True` |

Разница между `sorted(a)` и `a.sort()`: первая создаёт новый список, а `a` не трогает; вторая меняет сам `a` и ничего не возвращает. Частая ошибка: `a = a.sort()` — после этого в `a` будет `None` (ничего).

Среднее арифметическое: `sum(a) / len(a)`.

## 8. Как вывести список

```python
a = [1, 2, 3]
print(a)        # [1, 2, 3] — со скобками и запятыми
print(*a)       # 1 2 3 — через пробел, как обычно нужно в задачах
```

Звёздочка `*` «раскладывает» список на отдельные значения, как будто ты написал `print(1, 2, 3)`.

## 9. Пары соседних элементов (задание 17)

Типичная формулировка: «найдите количество пар **соседних** элементов, в которых хотя бы одно число делится на 3».

Соседние элементы — это `a[i]` и `a[i + 1]`. Перебираем `i` от 0 до **предпоследнего** индекса:

```python
a = [1, 3, 5, 7, 9]
cnt = 0
for i in range(len(a) - 1):
    if a[i] % 3 == 0 or a[i + 1] % 3 == 0:
        cnt += 1
print(cnt)    # 3
```

Пары: (1, 3) — да, (3, 5) — да, (5, 7) — нет, (7, 9) — да. Итого 3.

Почему `range(len(a) - 1)`, а не `range(len(a))`? У последнего элемента нет соседа справа. При `i = len(a) - 1` выражение `a[i + 1]` вышло бы за пределы списка, и была бы ошибка `IndexError: list index out of range`.

## 10. Множество — только уникальные значения

**Множество** (`set`) — это набор значений **без повторов**. Удобно, чтобы узнать, сколько различных чисел в списке:

```python
a = [3, 1, 3, 2, 1]
print(set(a))          # {1, 2, 3}
print(len(set(a)))     # 3 — различных значений
print(sorted(set(a)))  # [1, 2, 3]
```

## Частые ошибки

| Ошибка | Что не так |
|---|---|
| `a[len(a)]` | такого индекса нет, последний — `a[len(a) - 1]` или `a[-1]` |
| `a = a.sort()` | `sort` ничего не возвращает, в `a` окажется `None` |
| `range(len(a))` при обращении к `a[i + 1]` | `IndexError` на последнем шаге |
| `print(a)` вместо `print(*a)` | выведутся скобки и запятые, тест не пройдёт |
