# Урок 1. Установка Python и первая программа в IDLE

На ЕГЭ по информатике экзамен сдаётся на компьютере (КЕГЭ). Для заданий 2, 5, 6, 8, 12–17, 19–27 почти всегда быстрее написать короткую программу, чем решать руками. Python — самый популярный язык на экзамене: он короткий, понятный и в нём есть всё нужное «из коробки».

На станции КЕГЭ обычно установлены **Python + IDLE**, а часто и **PyCharm** / Wing IDE. Поэтому потренируйся в обоих: дома можно работать в PyCharm, но IDLE ты тоже должен уметь открыть и запустить.

## 1. Скачиваем Python

1. Открой сайт **python.org** → раздел **Downloads**.
2. Нажми жёлтую кнопку **Download Python 3.x.x** (бери последнюю версию 3.12+).
3. Запусти скачанный файл.

![Установщик Python: галочка Add python.exe to PATH](images/python-installer.svg)

> ⚠️ **Самое важное:** внизу первого окна установщика поставь галочку **«Add python.exe to PATH»**. Без неё Python не запустится из командной строки, и PyCharm может его не найти.

4. Нажми **Install Now** и дождись надписи **Setup was successful**.

### Проверяем установку

Нажми `Win + R`, введи `cmd`, нажми Enter. В чёрном окне набери:

```
python --version
```

Должно появиться что-то вроде `Python 3.13.0`. Если пишет «не является внутренней или внешней командой» — ты забыл галочку PATH. Запусти установщик ещё раз → **Modify** → **Next** → поставь **Add Python to environment variables**.

На macOS вместо `python` пиши `python3`.

## 2. IDLE — встроенная среда Python

IDLE ставится вместе с Python. Найди его в меню Пуск: **IDLE (Python 3.x)**.

У IDLE два режима — их важно не путать:

| Окно | Как выглядит | Для чего |
|---|---|---|
| **Shell** (оболочка) | строка `>>>` | проверить одну команду, посчитать |
| **Editor** (редактор) | пустой лист с номерами строк | писать программу целиком и сохранять |

### Shell: Python как калькулятор

![Окно IDLE Shell](images/idle-shell.svg)

После `>>>` пиши команду и жми Enter — результат сразу появится:

```python
>>> 2 + 3 * 4
14
>>> 2 ** 10
1024
>>> 17 // 5
3
>>> 17 % 5
2
```

Shell удобен для быстрых вычислений, но **программу в нём не пиши**: её нельзя сохранить и исправить.

### Editor: пишем и запускаем программу

1. В окне Shell: **File → New File** (`Ctrl + N`). Откроется пустое окно редактора.
2. Напиши программу:

```python
name = input('Как тебя зовут? ')
print('Привет,', name)
```

3. Сохрани: **File → Save** (`Ctrl + S`). Назови файл, например, `hello.py`. Расширение `.py` обязательно.
4. Запусти: **Run → Run Module** или клавиша **F5**.

![Окно редактора IDLE и меню Run](images/idle-editor.svg)

Программа выполнится в окне Shell: там появится вопрос, введи имя и нажми Enter.

### Полезные горячие клавиши IDLE

| Клавиши | Действие |
|---|---|
| `F5` | запустить программу |
| `Ctrl + S` | сохранить |
| `Ctrl + ]` / `Ctrl + [` | сдвинуть выделенный блок вправо / влево |
| `Alt + 3` / `Alt + 4` | закомментировать / раскомментировать |
| `Alt + P` (в Shell) | предыдущая команда |
| `Ctrl + C` (в Shell) | прервать зависшую программу |

## 3. Если программа зависла

Бывает, что программа считает очень долго (например, бесконечный цикл). В Shell нажми **Ctrl + C** — появится `KeyboardInterrupt`, программа остановится.

## 4. Ошибки — это нормально

Если в коде ошибка, Python напишет красный текст. Читай **последнюю строку** — там главное:

```
Traceback (most recent call last):
  File "hello.py", line 2, in <module>
    print('Привет', nme)
NameError: name 'nme' is not defined
```

Тут сказано: в строке 2 используется имя `nme`, которого нет (опечатка, должно быть `name`).

Частые ошибки новичков:

- `SyntaxError` — забыта скобка, кавычка или двоеточие.
- `IndentationError` — неправильные отступы.
- `NameError` — опечатка в имени переменной.
- `ValueError: invalid literal for int()` — пытаешься превратить в число не число.

## Как решать задачи на этой платформе

Под каждой задачей есть редактор кода и две кнопки:

- **▶ Запустить** — выполняет код с тем вводом, который ты напишешь в поле «Ввод».
- **✔ Проверить** — прогоняет программу на всех тестах. Задача зачтена, когда все тесты зелёные.

Выводи **ровно то, что просят**, без лишних слов вроде «Ответ:». Используй `input()` без подсказки внутри скобок — иначе подсказка попадёт в вывод и тест не пройдёт.
