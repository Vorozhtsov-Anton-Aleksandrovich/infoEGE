## 1. Системы счисления (задания 5, 14)

Из любой системы в десятичную — `int(строка, основание)`:

```python
int('1011', 2)    # 11
int('FF', 16)     # 255
int('210', 3)     # 21
```

Из десятичной — встроенные функции только для 2, 8, 16:

```python
bin(11)   # '0b1011' → bin(11)[2:] = '1011'
oct(8)    # '0o10'
hex(255)  # '0xff'
```

Для любого основания — делим с остатком и собираем остатки задом наперёд:

![Перевод числа в двоичную систему делением](images/base-convert.svg)

```python
def to_base(n, b):
    if n == 0:
        return '0'
    digits = '0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ'
    s = ''
    while n > 0:
        s = digits[n % b] + s
        n //= b
    return s

print(to_base(11, 2))   # 1011
print(to_base(100, 7))  # 202
```

## 2. Перебор слов (задание 8): `itertools`

```python
from itertools import product, permutations

# все слова длины 3 из букв А, Б, В (с повторами): 27 штук
for w in product('АБВ', repeat=3):
    s = ''.join(w)

# все перестановки букв слова (без повторов)
for w in permutations('ЛЕТО'):
    s = ''.join(w)
```

- `product(буквы, repeat=k)` — буквы **могут** повторяться;
- `permutations(буквы)` — каждая буква ровно один раз;
- `permutations(буквы, k)` — размещения из k букв.

Перестановки слова с повторяющимися буквами дают дубли — убирай через `set`:

```python
words = set(''.join(w) for w in permutations('МАМА'))
print(len(words))  # 6
```

## 3. Логика (задание 2): перебор таблицы истинности

```python
from itertools import product

for x, y, z, w in product([0, 1], repeat=4):
    F = ((x <= y) and (y == z)) or not w
    if F == 0:
        print(x, y, z, w)
```

## 4. Задание 15: «при каком наибольшем A выражение тождественно истинно»

Формула: `ДЕЛ(x, A) ∨ ¬ДЕЛ(x, 6) ∨ ¬ДЕЛ(x, 4)`. Перебираем A от большого к меньшему и проверяем, что формула верна **для всех** x — функция `all`:

```python
for A in range(1000, 0, -1):
    if all((x % A == 0) or (x % 6 != 0) or (x % 4 != 0) for x in range(1, 1000)):
        print(A)   # 12
        break
```

`all(...)` — истинно, если условие верно для каждого значения; `any(...)` — если хотя бы для одного.
