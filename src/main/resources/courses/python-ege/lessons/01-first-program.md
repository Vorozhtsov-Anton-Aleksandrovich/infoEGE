# Урок 1. Первая программа

Этот курс для тех, кто **ни разу не программировал**. Ничего устанавливать пока не нужно: все программы ты будешь писать и запускать прямо здесь, на сайте. Как поставить Python к себе на компьютер, разберём в конце курса, когда ты уже будешь уверенно писать код.

## Зачем это нужно на ЕГЭ

ЕГЭ по информатике сдают на компьютере. Примерно в половине заданий можно не решать задачу руками, а написать короткую программу, и она посчитает ответ за секунду. Например, «сколько чисел от 1 до 1 000 000 делятся на 7 и не делятся на 3» руками не посчитаешь, а программа из четырёх строк сделает это мгновенно.

Мы будем писать на языке **Python** (читается «па́йтон»). Это самый популярный язык на ЕГЭ: он короткий и понятный.

## Что такое программа

**Программа** — это список команд для компьютера. Компьютер выполняет их **строго по порядку, сверху вниз, по одной**, и делает ровно то, что написано, а не то, что ты имел в виду. Если в команде опечатка, компьютер её не поймёт и остановится с ошибкой.

Похоже на рецепт: «налей воды», «поставь на огонь», «подожди 5 минут». Только компьютер — очень послушный и очень буквальный повар.

## Как решать задачи на этом сайте

Под каждой задачей урока есть:

- **редактор кода** — белое поле с номерами строк слева, туда пишешь программу;
- поле **«Ввод»** — данные, которые программа «прочитает с клавиатуры» (про ввод будет в уроке 2);
- кнопка **▶ Запустить** — выполняет программу и показывает, что она вывела. Пробуй сколько угодно раз;
- кнопка **✔ Проверить** — сайт запускает программу на нескольких заранее подготовленных тестах и сравнивает её вывод с правильным. Если все тесты зелёные, задача решена.

Порядок работы всегда такой: **написал → запустил → посмотрел на результат → поправил → снова запустил → проверил**.

## Команда `print` — вывести на экран

Первая и самая важная команда — `print` (по-английски «печатать»). Она выводит на экран то, что написано в скобках.

```python
print('Привет!')
```

Результат:

```
Привет!
```

Разберём строку по кусочкам:

| Кусочек | Что это |
|---|---|
| `print` | имя команды. Пишется маленькими латинскими буквами, ровно так |
| `(` и `)` | скобки. В них то, что нужно вывести |
| `'Привет!'` | **текст** (в программировании говорят «строка»). Текст всегда в кавычках |

Кавычки можно ставить одинарные `'...'` или двойные `"..."` — разницы нет. Главное, чтобы открывающая и закрывающая кавычки были одинаковые. Кавычки на экран не выводятся: они лишь показывают Python'у, где текст начинается и где заканчивается.

> ⚠️ Кавычки и скобки нужно набирать **в английской раскладке**. Если ты печатаешь «ёлочки» `«»` или русские кавычки, Python их не поймёт.

### Несколько команд — несколько строк

Каждая команда пишется на отдельной строке. Каждый `print` выводит свою строку:

```python
print('Раз')
print('Два')
print('Три')
```

```
Раз
Два
Три
```

Компьютер выполнил три команды по очереди, сверху вниз.

### Пустая строка

`print()` с пустыми скобками выводит пустую строку — удобно, чтобы отделить части вывода.

```python
print('Начало')
print()
print('Конец')
```

```
Начало

Конец
```

## Числа и вычисления

Числа пишутся **без кавычек**. Тогда Python понимает, что это число, и может с ним считать:

```python
print(2 + 3)
print(10 - 4)
print(6 * 7)
print(15 / 3)
```

```
5
6
42
5.0
```

Обрати внимание:

- умножение — это звёздочка `*`, а не буква `х` и не точка;
- деление — косая черта `/`. Результат деления всегда дробный: `15 / 3` даёт `5.0`, а не `5`. Про «целое» деление поговорим в уроке 3;
- дробные числа пишутся **через точку**: `2.5`, а не `2,5`.

Порядок действий такой же, как в математике: сначала умножение и деление, потом сложение и вычитание. Скобки меняют порядок:

```python
print(2 + 3 * 4)     # 14: сначала 3 * 4 = 12, потом 2 + 12
print((2 + 3) * 4)   # 20: сначала скобка 2 + 3 = 5, потом 5 * 4
```

Возведение в степень — две звёздочки `**`:

```python
print(2 ** 3)    # 8, потому что 2 · 2 · 2 = 8
print(10 ** 6)   # 1000000
```

В Python целые числа могут быть **любой длины**: `2 ** 1000` посчитается точно, до последней цифры. Калькулятор так не умеет.

## Текст и число — разные вещи

Это очень важно понять с самого начала:

```python
print(2 + 3)       # 5   — это числа, Python их сложил
print('2 + 3')     # 2 + 3 — это текст в кавычках, Python вывел его как есть
```

Всё, что в кавычках, для Python — просто набор символов. Он не пытается его вычислить.

## Несколько значений в одном `print`

Внутри скобок можно перечислить несколько значений **через запятую**. Python выведет их в одну строку через пробел:

```python
print('Ответ:', 6 * 7)
```

```
Ответ: 42
```

Здесь два значения: текст `'Ответ:'` и число `6 * 7`. Пробел между ними Python поставил сам.

## Комментарии

Всё, что после знака `#` до конца строки, Python **пропускает**. Это **комментарий** — заметка для человека:

```python
# Эта программа считает площадь комнаты
print(5 * 4)   # длина 5 м, ширина 4 м
```

Комментарии помогают не запутаться в своём коде. В примерах этого курса справа от кода часто написан комментарий: что выведет строка.

## Ошибки — это нормально

Ошибаются все, даже опытные программисты. Если Python не понял команду, он не выполнит программу и напишет **сообщение об ошибке**. Не пугайся красного текста: он подсказывает, что не так.

Пример: забыли закрыть скобку.

```python
print('Привет'
```

```
SyntaxError: '(' was never closed
```

Как читать сообщение:

1. Смотри на **последнюю строку**: там название ошибки и объяснение.
2. Найди **номер строки** (`line 1`, `line 2`, …): ошибка там или чуть выше.
3. Переведи объяснение. Даже если не знаешь английский, помогут ключевые слова: `never closed` — «не закрыта».

Частые ошибки на первых шагах:

| Сообщение | Что случилось | Как исправить |
|---|---|---|
| `SyntaxError: '(' was never closed` | забыта закрывающая скобка | добавь `)` |
| `SyntaxError: unterminated string literal` | у текста нет закрывающей кавычки | добавь кавычку |
| `NameError: name 'Print' is not defined` | команда написана с большой буквы или с опечаткой | пиши `print` маленькими буквами |
| `NameError: name 'Привет' is not defined` | текст написан без кавычек | возьми текст в кавычки |
| `SyntaxError: invalid character '«'` | русские кавычки или «ёлочки» | переключи раскладку на английскую |

## Как тебя проверяют

Тесты сравнивают твой вывод с правильным **буква в букву**. Поэтому:

- выводи **ровно то, что просят**, без лишних слов вроде «Ответ:»;
- следи за большими и маленькими буквами: `Hello` и `hello` — разные строки;
- пробелы в конце строки и пустые строки в самом конце вывода не важны, остальное важно.
