# Урок 2. PyCharm — удобная среда для подготовки

IDLE простой, но для длинных программ неудобен. **PyCharm** подсказывает код, подсвечивает ошибки ещё до запуска и умеет пошаговую отладку — это очень помогает понять, *почему* программа выдаёт не тот ответ.

С 2025 года PyCharm — один продукт: первый месяц открыты все Pro-функции, потом основные функции остаются **бесплатными**. Для ЕГЭ хватает бесплатной части с запасом.

## 1. Установка

1. Сначала установи Python (урок 1). PyCharm сам Python **не** ставит.
2. Открой **jetbrains.com/pycharm/download**, скачай установщик для своей системы.
3. В установщике отметь:
   - **Create Desktop Shortcut** — ярлык на рабочем столе;
   - **Add "Open Folder as Project"**;
   - **.py** — открывать `.py` файлы в PyCharm.
4. **Next → Install**, после установки запусти PyCharm.

> Если сайт JetBrains не открывается, попроси преподавателя скинуть установщик. Пока PyCharm нет — решай в IDLE, разницы для задач нет.

## 2. Создаём проект

PyCharm работает с **проектами** — это просто папка с твоими файлами.

1. На стартовом экране нажми **New Project**.
2. **Name**: `ege` (имя папки проекта).
3. **Location**: где будет лежать папка, например `C:\Users\Имя\PycharmProjects`.
4. **Interpreter type**: оставь **Project venv**, в поле **Python version** должна стоять твоя версия Python.
5. Галочку **Create a welcome script** можно снять.
6. Нажми **Create**.

![Окно New Project в PyCharm](images/pycharm-new-project.svg)

Если в поле Python version пусто или написано *No interpreter* — Python не установлен или установлен без PATH. Вернись к уроку 1.

## 3. Создаём файл и запускаем

1. Слева панель **Project**. Нажми правой кнопкой по папке `ege` → **New → Python File**.
2. Введи имя, например `task5`, нажми Enter (`.py` допишется сам).
3. Напиши код:

```python
for n in range(1, 6):
    print(n, n * n)
```

4. Запусти одним из способов:
   - правой кнопкой по коду → **Run 'task5'**;
   - зелёный треугольник ▶ сверху справа;
   - `Ctrl + Shift + F10` (запустить текущий файл), потом `Shift + F10` (повторить).

![Запуск в PyCharm и окно Run](images/pycharm-run.svg)

Внизу откроется окно **Run** — там вывод программы. Если программа ждёт `input()`, кликни в это окно и вводи данные там.

Остановить программу — красный квадрат ■ в окне Run (или `Ctrl + F2`).

## 4. Подсказки и подсветка ошибок

- Красное подчёркивание — ошибка синтаксиса. Наведи мышь — увидишь объяснение.
- Жёлтая / серая подсветка — предупреждение (например, переменная не используется). Программа запустится.
- Начни писать `pri` — PyCharm предложит `print`. Жми `Tab` или `Enter`.

## 5. Отладчик — смотрим, как работает программа

Это главная причина пользоваться PyCharm при подготовке.

1. Кликни слева от номера строки — появится красная точка (**breakpoint**, точка останова).
2. Запусти программу **жуком** 🐞 (**Debug**) вместо треугольника, или `Shift + F9`.
3. Программа остановится на этой строке. Внизу во вкладке **Debugger / Threads & Variables** видны **все переменные и их значения**.
4. Нажимай **F8** (*Step Over*) — выполнится одна строка, значения переменных обновятся.
5. **F9** (*Resume*) — продолжить до следующей точки останова.

![Отладчик PyCharm: точка останова и переменные](images/pycharm-debug.svg)

Так ты увидишь, на каком шаге цикла переменная получила неправильное значение.

## 6. Горячие клавиши PyCharm

| Клавиши | Действие |
|---|---|
| `Ctrl + Shift + F10` | запустить текущий файл |
| `Shift + F10` | повторить последний запуск |
| `Shift + F9` | запустить в отладчике |
| `F8` | шаг (в отладчике) |
| `Ctrl + /` | закомментировать строку / выделение |
| `Ctrl + D` | дублировать строку |
| `Tab` / `Shift + Tab` | сдвинуть блок вправо / влево |
| `Ctrl + Alt + L` | отформатировать код |
| `Shift + F6` | переименовать переменную везде |

## 7. Файлы к заданиям в PyCharm

В заданиях 9, 17, 24, 26, 27 дают файл (`9.txt`, `17.txt` …). Чтобы программа его нашла по имени, **положи файл в папку проекта** (перетащи мышкой в панель Project). Тогда работает `open('17.txt')`.

## IDLE или PyCharm на экзамене?

Без разницы — код одинаковый. На экзамене открывай то, что установлено и что тебе привычнее. Главное: умей создать файл, запустить его и найти вывод.

## Практика

Реши задачи ниже в редакторе на сайте, а одну — повтори в PyCharm с отладчиком: поставь точку останова внутри цикла и посмотри, как меняется переменная.
