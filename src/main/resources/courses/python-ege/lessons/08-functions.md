# Урок 8. Функции

Функция — это кусок кода с именем, который можно вызывать много раз. На ЕГЭ функции нужны в заданиях 16 (рекурсия), 23, 25 (делители) и просто чтобы код был понятным.

## 1. Как объявить и вызвать

```python
def square(x):
    return x * x

print(square(5))      # 25
print(square(3) + 1)  # 10
```

![Функция: аргументы → тело → return](images/function.svg)

- `def` — объявление, дальше имя и параметры в скобках, двоеточие;
- тело — с отступом;
- `return` возвращает результат **и сразу завершает функцию**.

Функция без `return` возвращает `None`.

## 2. Несколько параметров и результатов

```python
def min_max(a, b):
    if a < b:
        return a, b
    return b, a

lo, hi = min_max(9, 4)    # lo = 4, hi = 9
```

## 3. Функция-проверка

```python
def is_prime(n):
    if n < 2:
        return False
    d = 2
    while d * d <= n:
        if n % d == 0:
            return False
        d += 1
    return True
```

Проверяем делители только до корня из `n`: если у `n` есть делитель больше корня, то парный ему — меньше корня, и мы его уже нашли. Так быстро даже для чисел порядка миллиарда.

## 4. Делители числа (задание 25)

```python
def divisors(n):
    res = []
    d = 1
    while d * d <= n:
        if n % d == 0:
            res.append(d)
            if d != n // d:
                res.append(n // d)
        d += 1
    return sorted(res)

print(divisors(36))   # [1, 2, 3, 4, 6, 9, 12, 18, 36]
```

## 5. Рекурсия (задание 16)

Рекурсия — функция вызывает саму себя. Обязательно нужен **базовый случай**, где она не вызывает себя, иначе будет бесконечно.

Пример из задания 16: `F(1) = 1`, `F(n) = F(n − 1) + 2·n` при `n > 1`.

```python
def F(n):
    if n == 1:
        return 1
    return F(n - 1) + 2 * n

print(F(4))   # 1 + 4 + 6 + 8 = 19
```

Для больших `n` Python упирается в лимит глубины (≈1000). Помогают:

```python
import sys
sys.setrecursionlimit(10000)
```

или кэш, чтобы одинаковые значения не пересчитывались:

```python
from functools import lru_cache

@lru_cache(None)
def F(n):
    ...
```
