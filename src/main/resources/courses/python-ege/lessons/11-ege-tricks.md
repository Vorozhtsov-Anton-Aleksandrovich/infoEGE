## 1. Системы счисления (задания 5, 14)

Мы привыкли к десятичной системе: цифры от 0 до 9. В двоичной системе цифр только две: 0 и 1. В шестнадцатеричной — шестнадцать: 0–9 и буквы A–F (A = 10, B = 11, …, F = 15).

### Из любой системы в десятичную: `int(строка, основание)`

Ты уже знаешь `int('17')`. Если передать вторым аргументом основание, `int` прочитает запись в этой системе:

```python
print(int('1011', 2))    # 11
print(int('FF', 16))     # 255
print(int('210', 3))     # 21
```

Проверим первое вручную: `1011` в двоичной = 1·8 + 0·4 + 1·2 + 1·1 = 11.

> ⚠️ Первый аргумент — **строка** в кавычках, а не число.

### Из десятичной в двоичную, восьмеричную, шестнадцатеричную

Для этих трёх систем есть готовые функции:

```python
print(bin(11))       # 0b1011
print(bin(11)[2:])   # 1011 — без приставки '0b'
print(oct(8)[2:])    # 10
print(hex(255)[2:])  # ff
```

Функции добавляют в начало два служебных символа (`0b`, `0o`, `0x`). Срез `[2:]` их отрезает.

### В любую систему — своей функцией

Для других оснований (3, 5, 7…) готовой функции нет. Число переводят делением с остатком: делим на основание, записываем остаток, повторяем, а потом читаем остатки **снизу вверх**.

![Перевод числа в двоичную систему делением](images/base-convert.svg)

```python
def to_base(n, b):
    if n == 0:
        return '0'
    digits = '0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ'
    s = ''
    while n > 0:
        s = digits[n % b] + s    # остаток — очередная цифра, приписываем СЛЕВА
        n //= b
    return s

print(to_base(11, 2))    # 1011
print(to_base(100, 7))   # 202
```

Строка `digits` нужна, чтобы остаток 10 превратился в `A`, 11 — в `B` и т. д.: `digits[10]` — это `'A'`.

### Подсчёт цифр в записи числа (задание 14)

Часто спрашивают: «сколько цифр X в записи числа в системе с основанием B». Строку строить не обязательно: остатки и есть цифры, считай прямо в цикле.

```python
n = 9**20 + 3**15
cnt = 0
while n > 0:
    if n % 3 == 0:       # очередная цифра в троичной записи — 0?
        cnt += 1
    n //= 3
print(cnt)
```

Это тот же шаблон, что и для десятичных цифр в уроке 6, только вместо 10 — основание системы.

## 2. Перебор слов (задание 8): `itertools`

В задании 8 нужно посчитать слова, составленные из заданных букв по каким-то правилам. Перебрать все варианты помогает стандартная библиотека `itertools`. Её подключают строкой `from itertools import ...` в начале программы.

### `product` — с повторами

`product(буквы, repeat=k)` перебирает все слова длины `k`, где **буквы могут повторяться**:

```python
from itertools import product

for w in product('АБ', repeat=2):
    print(w)
```

```
('А', 'А')
('А', 'Б')
('Б', 'А')
('Б', 'Б')
```

Каждое слово приходит как **кортеж** (похож на список, но в круглых скобках). Чтобы склеить его в строку, используй `''.join(w)`:

```python
from itertools import product

cnt = 0
for w in product('АБВ', repeat=3):
    s = ''.join(w)          # 'ААА', 'ААБ', ...
    if s.count('А') == 1:   # ровно одна буква А
        cnt += 1
print(cnt)    # 12
```

### `permutations` — перестановки без повторов

`permutations(буквы)` перебирает все способы переставить буквы, **каждая используется ровно один раз**:

```python
from itertools import permutations

for w in permutations('КОТ'):
    print(''.join(w))
```

```
КОТ
КТО
ОКТ
ОТК
ТКО
ТОК
```

Если в слове есть **одинаковые** буквы, перестановки будут повторяться. Убирай повторы через множество:

```python
from itertools import permutations

words = set(''.join(w) for w in permutations('МАМА'))
print(len(words))    # 6
```

## 3. Таблица истинности (задание 2)

В задании 2 нужно перебрать все наборы значений переменных 0 и 1. Это тот же `product`, только из `[0, 1]`:

```python
from itertools import product

print('x y z w')
for x, y, z, w in product([0, 1], repeat=4):
    F = ((not x or y) and (y == z)) or not w
    if not F:
        print(x, y, z, w)
```

Программа выведет все строки таблицы, где `F` ложна. Как записывать логические значки на Python, смотри в уроке 4.

## 4. «Для всех» и «хотя бы один»: `all` и `any` (задание 15)

- `all(условие for x in ...)` — `True`, если условие верно для **каждого** значения;
- `any(условие for x in ...)` — `True`, если условие верно **хотя бы для одного**.

```python
print(all(x > 0 for x in [3, 5, 1]))    # True — все положительные
print(any(x > 4 for x in [3, 5, 1]))    # True — есть 5
```

Задание 15: «при каком **наибольшем** A формула `ДЕЛ(x, A) ∨ ¬ДЕЛ(x, 6) ∨ ¬ДЕЛ(x, 4)` истинна при **любом** x». Здесь `ДЕЛ(x, A)` значит «x делится на A». Перебираем A от большого к меньшему и для каждого проверяем формулу на всех x:

```python
for A in range(1000, 0, -1):
    if all((x % A == 0) or (x % 6 != 0) or (x % 4 != 0) for x in range(1, 1000)):
        print(A)    # 12
        break
```

Перебор идёт **сверху вниз**, поэтому первое подходящее A и есть наибольшее, после чего `break`.
