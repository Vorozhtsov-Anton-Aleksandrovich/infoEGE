# Урок 6. Сортировка, фильтры, условное форматирование

:::note Зачем это нужно
Сортировка и фильтры отвечают на вопросы «какой пятый по величине», «сколько записей из Казани дороже 5000» без единой формулы. В **задании 3** фильтр — один из двух основных способов решения. Условное форматирование помогает глазами увидеть повторы и выбросы.
:::

## 1. Сортировка

Сортировка переставляет строки таблицы по значениям одного столбца: по возрастанию (А→Я, 1→9) или по убыванию.

:::steps Как отсортировать таблицу по убыванию суммы
1. Встань в **любую** ячейку таблицы (не выделяй столбец!).
2. **Данные → Сортировка**.
3. Excel сам выделит всю таблицу. Проверь галочку «Мои данные содержат заголовки».
4. «Сортировать по» — **Сумма**, «Порядок» — **По убыванию**. ОК.
:::

![СКРИНШОТ: окно «Сортировка» Excel: столбец «Сумма», порядок «По убыванию», галочка «Мои данные содержат заголовки»](images/todo-sort-dialog.png)

**В LibreOffice:** **Данные → Сортировать…**, вкладка «Параметры» → «Диапазон содержит заголовки столбцов».

**Сортировка по нескольким столбцам**: в том же окне кнопка «Добавить уровень» — например, сначала по городу, а внутри города — по сумме.

:::warn Выделяй всю таблицу, иначе строки «разъедутся»
Если выделить только один столбец и отсортировать его, Excel переставит **только этот столбец**. Фамилии перемешаются с чужими баллами — данные испорчены.
:::

![Отсортировали только столбец с именами — баллы остались на месте, таблица испорчена](images/xl-sort-wrong.svg)

Excel обычно спрашивает «Автоматически расширить выделенный диапазон?» — соглашайся. А надёжнее всего — вставать в одну ячейку, как в разборе выше.

:::try Как без сортировки найти 5-е по величине число в E2:E401? ||| Функцией **НАИБОЛЬШИЙ**: `=НАИБОЛЬШИЙ(E2:E401;5)`. А 5-е с конца — **НАИМЕНЬШИЙ**(E2:E401;5). :::

## 2. Фильтр

Фильтр **прячет** строки, которые не подходят под условие. Сами данные не меняются — сняв фильтр, всё вернёшь.

:::steps Как включить фильтр
1. Встань в любую ячейку таблицы.
2. **Данные → Фильтр** (или Ctrl + Shift + L).
3. В заголовках появятся кнопки ▾.
4. Нажми ▾ у нужного столбца и сними лишние галочки — останутся только нужные строки.
:::

![Фильтр по городу: видны только строки Казани, внизу строка состояния](images/xl-filter.svg)

**В LibreOffice:** **Данные → Автофильтр**.

Для чисел есть **Числовые фильтры**: больше, меньше, между, первые 10. Для текста — **Текстовые фильтры**: начинается с, содержит, заканчивается на.

![СКРИНШОТ: открытое меню фильтра числового столбца с пунктом «Числовые фильтры → больше…»](images/todo-filter-menu.png)

Фильтры в разных столбцах **складываются**: «Город = Казань» и «Сумма > 5000» оставят строки, где выполнено и то, и другое.

### Строка состояния после фильтра

Выдели видимые ячейки столбца — внизу Excel покажет количество и сумму **только видимых** строк. Это быстрый способ получить ответ.

:::warn Частая ошибка
Формула `=СУММ(E2:E401)` сложит **все** строки, включая скрытые фильтром. Для суммы только видимых нужна **ПРОМЕЖУТОЧНЫЕ.ИТОГИ**(9; E2:E401) — или сразу считать без фильтра функцией **СУММЕСЛИМН**.
:::

Снять все фильтры: **Данные → Очистить**. Выключить фильтр — ещё раз **Данные → Фильтр**.

## 3. Условное форматирование

Условное форматирование **раскрашивает** ячейки, подходящие под правило. Данные не меняются — меняется только вид.

**Главная → Условное форматирование → Правила выделения ячеек** → «Больше», «Меньше», «Между», «Повторяющиеся значения»…

![Повторяющиеся значения подсвечены красным](images/xl-duplicates.svg)

![СКРИНШОТ: меню «Условное форматирование» с раскрытым подменю «Правила выделения ячеек»](images/todo-cond-format-menu.png)

**В LibreOffice:** **Формат → Условное форматирование → Условие…**; для повторов — условие «повторяющиеся».

**Правило с формулой**: «Создать правило → Использовать формулу». Например, `=ОСТАТ($C2;2)=0` подсветит строки с чётным баллом. Формулу пишут для первой строки выделения, со знаком $ перед буквой столбца.

После раскраски по цвету можно фильтровать: ▾ → **Фильтр по цвету**.

## 4. Уникальные значения и удаление дубликатов

«Сколько **различных** клиентов в таблице?» — три способа:

1. **Excel 365:** `=СЧЁТЗ(УНИК(D2:D401))`. Функция **УНИК** (UNIQUE) есть не во всех версиях.
2. **Удалить дубликаты:** скопируй столбец на новый лист → **Данные → Удалить дубликаты** → посчитай оставшиеся строки (Ctrl + ↓).
   **В LibreOffice:** **Данные → Ещё фильтры → Стандартный фильтр**, условие «Клиент — не пусто», в «Параметрах» галочка **«Без повторений»**.
3. **Формула для любой версии:** `=СУММПРОИЗВ(1/СЧЁТЕСЛИ(D2:D401;D2:D401))`. Каждая фамилия, встречающаяся k раз, даст k слагаемых по 1/k — в сумме ровно 1.

![СКРИНШОТ: окно «Стандартный фильтр» LibreOffice с раскрытыми параметрами и галочкой «Без повторений»](images/todo-lo-standard-filter.png)

:::quiz
Что сделает **Данные → Удалить дубликаты**, если выделить таблицу из трёх столбцов и отметить только столбец «Город»?
- [ ] Оставит все строки, но сотрёт повторы в столбце «Город»
- [x] Оставит по одной строке на каждый город, остальные строки удалит целиком
- [ ] Ничего, нужно выделять один столбец
---
Удаление дубликатов удаляет **строки целиком** — по одной на каждое значение отмеченных столбцов. Поэтому для подсчёта различных значений работай с **копией** столбца на отдельном листе.
:::

## 5. Шпаргалка урока

:::cheat
- Сортировка: встань в таблицу → **Данные → Сортировка**. Никогда не сортируй один столбец отдельно.
- Без сортировки: **НАИБОЛЬШИЙ**(диапазон; k), **НАИМЕНЬШИЙ**(диапазон; k).
- Фильтр: **Данные → Фильтр** (в LibreOffice — Автофильтр). Условия в разных столбцах складываются.
- Строка состояния показывает сумму видимых выделенных ячеек; СУММ считает и скрытые.
- Условное форматирование: **Главная → Условное форматирование**; повторы — «Повторяющиеся значения».
- Различных значений: `=СУММПРОИЗВ(1/СЧЁТЕСЛИ(D2:D401;D2:D401))` или удалить дубликаты в копии.
:::
