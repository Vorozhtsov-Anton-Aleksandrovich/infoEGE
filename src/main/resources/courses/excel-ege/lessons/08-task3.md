# Урок 8. Задание 3: базы данных

:::note Зачем это нужно
**Задание 3** ЕГЭ: файл с тремя листами — «Движение товаров», «Товар», «Магазин». Нужно ответить на вопрос вроде «на сколько увеличилось количество упаковок яиц в магазинах Заречного района за первую декаду июня». Решается одним алгоритмом: **подтянуть недостающие поля функцией ВПР → отфильтровать → сложить**.
:::

## 1. Что такое база данных

**База данных** — несколько таблиц, связанных между собой. Чтобы не повторять одно и то же тысячи раз, данные разносят по разным листам:

- **«Движение товаров»** — главная таблица, тысячи строк: каждая строка — одна операция (поступление или продажа).
- **«Товар»** — справочник товаров: артикул, отдел, наименование, сколько в упаковке.
- **«Магазин»** — справочник магазинов: ID, район, адрес.

![Три листа и связи между ними: по ID магазина и по артикулу](images/xl-db-schema.svg)

В «Движении товаров» нет названия товара и района — только **артикул** и **ID магазина**. Это **ключи**: по ним находят нужную строку в справочнике. Одной строке справочника соответствует много строк движения — связь «один ко многим».

:::try Почему бы не написать название товара прямо в «Движении товаров»? ||| Тогда одно название повторилось бы сотни раз, а при переименовании товара пришлось бы исправлять каждую строку. С ключом название хранится в одном месте. :::

## 2. ВПР — подтянуть значение из другой таблицы

**ВПР**(что ищем; где ищем; номер столбца ответа; ЛОЖЬ)

![ВПР ищет артикул 17 в первом столбце листа «Товар» и берёт 3-й столбец той же строки](images/xl-vlookup.svg)

`=ВПР(D2;Товар!$A$2:$F$13;3;ЛОЖЬ)`:

1. берёт артикул из D2;
2. ищет его в **первом** столбце диапазона Товар!A2:F13;
3. возвращает значение из **3-го** столбца найденной строки — наименование;
4. **ЛОЖЬ** — искать точное совпадение. Без него ВПР может вернуть «похожую» строку — неверный ответ.

:::warn Частые ошибки с ВПР
- Забыть **ЛОЖЬ** в конце.
- Забыть **$** в диапазоне справочника: при протягивании вниз диапазон съедет, и нижние строки дадут #Н/Д.
- Искомое значение должно быть в **первом** столбце диапазона. Нумерация столбцов — от начала диапазона, а не от столбца A.
:::

Диапазон на другом листе удобно выбирать мышью: пока пишешь формулу, щёлкни по ярлыку листа «Товар» и выдели нужное — Excel сам допишет `Товар!A2:F13`.

### Другие функции поиска

- **ИНДЕКС + ПОИСКПОЗ**: `=ИНДЕКС(Товар!C2:C13;ПОИСКПОЗ(D2;Товар!A2:A13;0))` — то же, что ВПР, но искомый столбец может быть где угодно.
- **ПРОСМОТРX** (XLOOKUP): `=ПРОСМОТРX(D2;Товар!A2:A13;Товар!C2:C13)` — самый удобный, но есть **только в Excel 2021/365**. На станции ЕГЭ его может не быть, а в старом LibreOffice — тоже. Надёжнее всего ВПР.

## 3. Алгоритм решения задания 3

:::steps Шаги
1. Прочитай вопрос и выпиши, **какие поля нужны**: район? наименование? отдел? количество в упаковке?
2. На листе «Движение товаров» справа от данных добавь **вспомогательные столбцы** с ВПР для каждого нужного поля.
3. Протяни их на все строки (двойной щелчок по маркеру).
4. Дальше один из двух путей:
   - **фильтр** по всем условиям и сумма в строке состояния;
   - **СУММЕСЛИМН** с условиями — надёжнее, ответ сразу в ячейке.
5. Перечитай вопрос: упаковки или килограммы? поступление или продажа? какой период?
:::

## 4. Разбор типовой задачи

> На сколько увеличилось количество упаковок товара «Молоко 3,2%» в магазинах Октябрьского района за июнь?

«Увеличилось» = **поступило минус продано**.

:::steps Решение
1. Нужны поля: **район** (из «Магазина») и **наименование** (из «Товара»).
2. H2 «Район»: `=ВПР(C2;Магазин!$A$2:$C$19;2;ЛОЖЬ)`.
3. I2 «Наименование»: `=ВПР(D2;Товар!$A$2:$F$13;3;ЛОЖЬ)`.
4. Протянуть H2:I2 вниз.
5. Поступило: `=СУММЕСЛИМН(F:F;I:I;"Молоко 3,2%";H:H;"Октябрьский";E:E;"Поступление")`.
6. Продано: то же самое с «Продажа».
7. Ответ — разность.
:::

Фильтром: «Наименование» = Молоко 3,2%, «Район» = Октябрьский, «Тип операции» = Поступление → выдели видимые ячейки F → сумма в строке состояния. Потом поменяй тип на «Продажа» и вычти.

## 5. Ловушки задания 3

### Период дат

«С 1 по 10 июня включительно» → в СУММЕСЛИМН два условия на дату:
`B:B;">="&ДАТА(2021;6;1);B:B;"<="&ДАТА(2021;6;10)`.

В фильтре: ▾ у «Даты» → Фильтры по дате → **Между**.

### Упаковки или килограммы

Если спрашивают **килограммы**, а в «Движении» записаны **упаковки**, нужен ещё столбец «Количество в упаковке» (ВПР, 5-й столбец «Товара») и столбец «Килограммы» = упаковки × количество в упаковке.

### Выручка

Выручка операции = количество упаковок × цена. Делаем столбец `=F2*G2` и складываем его.

:::warn Частая ошибка
Перед СУММЕСЛИМН проверь, что текст в условии совпадает **буква в букву**: «Молоко 3,2%», а не «Молоко 3.2%» или «молоко». Лучше скопировать название прямо из таблицы.
:::

## 6. В LibreOffice

ВПР, ИНДЕКС, ПОИСКПОЗ, СУММЕСЛИМН — те же. Фильтр — **Данные → Автофильтр**. Ссылка на другой лист пишется через точку: `$Товар.A2:F13` — но если выделять мышью, программа подставит правильную запись сама.

## 7. Шпаргалка урока

:::cheat
- Ключи: **ID магазина** → лист «Магазин», **Артикул** → лист «Товар».
- `=ВПР(ключ;Справочник!$A$2:$F$N;номер_столбца;ЛОЖЬ)` — подтянуть поле. Не забудь **$** и **ЛОЖЬ**.
- Алгоритм: нужные поля → ВПР во вспомогательные столбцы → протянуть → СУММЕСЛИМН (или фильтр).
- «Увеличилось» = поступление − продажа. Килограммы = упаковки × количество в упаковке. Выручка = упаковки × цена.
- Даты: `">="&ДАТА(2021;6;1)`.
- ПРОСМОТРX — только в новых Excel.
:::
