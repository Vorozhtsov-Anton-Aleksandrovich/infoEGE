# Урок 7. Задание 9: анализ строк таблицы

:::note Зачем это нужно
**Задание 9** ЕГЭ: в файле несколько тысяч строк, в каждой 3–7 чисел. Нужно найти, сколько строк удовлетворяют двум условиям — например, «одно число повторяется дважды» и «среднее остальных не больше повторяющегося». Решается за 5–10 минут одним приёмом: **каждое условие — свой вспомогательный столбец**.
:::

## 1. Как выглядит задание

> Откройте файл электронной таблицы, содержащей в каждой строке шесть натуральных чисел. Определите количество строк таблицы, для которых выполнены оба условия:
> — в строке только одно число повторяется дважды, остальные четыре числа различны;
> — среднее арифметическое неповторяющихся чисел строки не больше повторяющегося числа.

Данные — в A:F, строк 5000. Заголовков нет: числа начинаются с первой строки.

## 2. Метод: столбец на каждое условие

1. Разбей условие на маленькие кусочки.
2. Каждый кусочек — **отдельный столбец** справа от данных, формула в **первой** строке.
3. Последний столбец — «всё вместе»: `=ЕСЛИ(И(…);1;0)` или произведение единиц.
4. Выдели формулы первой строки и **дважды щёлкни** по маркеру — они протянутся на все строки.
5. Ответ: **СУММ** последнего столбца.

![Данные A:F, столбец условия 1, столбец среднего и итоговый столбец](images/xl-task9-columns.svg)

Главное преимущество: каждое условие видно глазами, легко проверить пару строк вручную.

## 3. Функции для повторов

Как понять, сколько раз встречается число в строке? **СЧЁТЕСЛИ** по строке:

`=СЧЁТЕСЛИ($A1:$F1;A1)` — сколько раз число из A1 встречается в A1:F1.

Протянем вправо на 6 столбцов (G1:L1) — получим «кратность» каждого числа строки:

| A | B | C | D | E | F | | G | H | I | J | K | L |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 5 | 12 | 5 | 7 | 3 | 9 | | <span class="hl-orange">2</span> | 1 | <span class="hl-orange">2</span> | 1 | 1 | 1 |

Знаки $ перед буквами нужны, чтобы диапазон $A1:$F1 **не съезжал вправо** при копировании, но съезжал вниз со строкой.

По кратностям легко проверять шаблоны:

| Условие | Проверка по G:L |
|---|---|
| все числа различны | `МАКС(G1:L1)=1` |
| ровно одно число повторяется дважды, остальные различны | `СЧЁТЕСЛИ(G1:L1;2)=2` и `СЧЁТЕСЛИ(G1:L1;1)=4` |
| одно число трижды, остальные три различны | `СЧЁТЕСЛИ(G1:L1;3)=3` и `СЧЁТЕСЛИ(G1:L1;1)=3` |
| сумма повторяющихся | `СУММЕСЛИ(G1:L1;2;A1:F1)` |
| среднее неповторяющихся | `СРЗНАЧЕСЛИ(G1:L1;1;A1:F1)` |

Ещё полезные функции:

- **НАИБОЛЬШИЙ**(A1:F1; k) и **НАИМЕНЬШИЙ**(A1:F1; k) — k-е по величине число строки.
- **СУММКВ**(A1:E1) — сумма квадратов.
- Количество различных чисел: `СУММПРОИЗВ(1/СЧЁТЕСЛИ(A1:G1;A1:G1))`.

:::try Почему СЧЁТЕСЛИ(G1:L1;2)=2, а не 1, если повторяется одно число? ||| Повторяющееся число стоит в двух ячейках, и у каждой из них кратность 2. Поэтому двоек среди G:L — **две**. :::

## 4. Разбор 1: повторяющееся число и среднее

:::steps Решение задачи из пункта 1
1. **G1:L1 — кратности.** В G1: `=СЧЁТЕСЛИ($A1:$F1;A1)`, протяни вправо до L1.
2. **M1 — первое условие** (ровно одно число дважды): `=ЕСЛИ(И(СЧЁТЕСЛИ(G1:L1;2)=2;СЧЁТЕСЛИ(G1:L1;1)=4);1;0)`.
3. **N1 — второе условие.** Повторяющееся число = `СУММЕСЛИ(G1:L1;2;A1:F1)/2` (оно сложилось дважды). Среднее остальных = `СРЗНАЧЕСЛИ(G1:L1;1;A1:F1)`. Формула: `=ЕСЛИ(M1=1;СРЗНАЧЕСЛИ(G1:L1;1;A1:F1)<=СУММЕСЛИ(G1:L1;2;A1:F1)/2;ЛОЖЬ)`.
4. **O1 — оба условия:** `=ЕСЛИ(И(M1=1;N1);1;0)`.
5. Выдели **G1:O1** и дважды щёлкни по маркеру — формулы протянутся на все 5000 строк.
6. Ответ: `=СУММ(O:O)`.
:::

Зачем в N1 проверка `ЕСЛИ(M1=1;…)`? Если повторов нет, СРЗНАЧЕСЛИ по пустому набору даст ошибку #ДЕЛ/0!, и СУММ по столбцу тоже станет ошибкой.

## 5. Разбор 2: треугольник

> В каждой строке три натуральных числа. Сколько строк, из чисел которых можно составить невырожденный **равнобедренный** треугольник?

:::steps Решение
1. Треугольник существует, если **наибольшая сторона меньше суммы двух других**. Сумма двух других = СУММ − МАКС. **D1:** `=ЕСЛИ(МАКС(A1:C1)<СУММ(A1:C1)-МАКС(A1:C1);1;0)`.
2. Равнобедренный — есть две одинаковые стороны. **E1:** `=ЕСЛИ(ИЛИ(A1=B1;B1=C1;A1=C1);1;0)`.
3. **F1:** `=D1*E1` — произведение равно 1, только если оба условия выполнены.
4. Протяни D1:F1 вниз, ответ `=СУММ(F:F)`.
:::

:::warn Частые ошибки
- Забыть $ в `$A1:$F1` — при протягивании вправо диапазон съедет на соседние столбцы.
- Протянуть формулы не до конца: проверь Ctrl + ↓ в последнем столбце — он должен заканчиваться на той же строке, что и данные.
- Считать СЧЁТЕСЛИ по всему столбцу вместо строки.
- «Хотя бы два одинаковых» и «ровно два одинаковых» — разные условия. Читай условие медленно.
:::

## 7. Шпаргалка урока

:::cheat
- Каждое условие — свой столбец справа от данных; итог — `ЕСЛИ(И(…);1;0)` или произведение; ответ — **СУММ**.
- Кратность числа в строке: `=СЧЁТЕСЛИ($A1:$F1;A1)`, протянуть вправо.
- Ровно один повтор: `СЧЁТЕСЛИ(кратн;2)=2`; все различны: `МАКС(кратн)=1`.
- Сумма повторяющихся: `СУММЕСЛИ(кратн;2;данные)`; среднее неповторяющихся: `СРЗНАЧЕСЛИ(кратн;1;данные)`.
- **НАИБОЛЬШИЙ / НАИМЕНЬШИЙ**, **СУММКВ**. Треугольник: МАКС < СУММ − МАКС.
- Выдели формулы первой строки → двойной щелчок по маркеру.
:::
