# Урок 9. Задание 18: робот на клетчатом поле

:::note Зачем это нужно
**Задание 18** ЕГЭ: поле из клеток с монетами, Робот идёт из левого верхнего угла в правый нижний, делая шаги только **вправо** или **вниз**. Нужно найти **максимальную и минимальную** сумму монет. Перебрать все пути вручную невозможно (на поле 15×15 их сотни миллионов), а в Excel задача решается **одной формулой**, протянутой на всё поле.
:::

## 1. Условие

> Квадрат разлинован на N×N клеток. Робот за один ход перемещается на одну клетку вправо или вниз. В каждой клетке лежит монета. Посетив клетку, Робот забирает монету, в том числе в начальной и конечной клетках. Определите максимальную и минимальную сумму, которую может собрать Робот.

В ответе — **два числа через пробел**: сначала максимум, потом минимум.

## 2. Главная идея: «лучшая сумма до клетки»

Посмотри на любую клетку. В неё Робот может прийти только **сверху** или **слева** — других ходов нет. Значит:

**лучшая сумма до клетки = монета в клетке + лучшая из сумм (до клетки сверху, до клетки слева)**

Если мы знаем лучшие суммы для соседей сверху и слева, сумму для клетки посчитать легко. А соседи посчитаются так же — по своим соседям. Начинаем с левого верхнего угла и заполняем таблицу строка за строкой. Это **динамическое программирование**.

![Поле 4×4 и таблица лучших сумм: B2 = 5 + МАКС(4; 5) = 10](images/xl-robot-dp.svg)

:::steps Заполняем таблицу для поля 4×4 руками
1. Старт A1: монета 3 → **3**.
2. Первая строка: прийти можно только слева. B1 = 3 + 1 = 4, C1 = 4 + 4 = 8, D1 = 8 + 2 = 10.
3. Первый столбец: только сверху. A2 = 3 + 2 = 5, A3 = 5 + 6 = 11, A4 = 11 + 1 = 12.
4. B2: сверху 4, слева 5. Лучший — 5. B2 = 5 + 5 = **10**.
5. Остальные клетки — так же. Правая нижняя клетка — ответ: **22**.
6. Для минимума — то же самое, но берём **меньшего** из соседей.
:::

:::try Почему нельзя просто идти в соседнюю клетку с самой большой монетой? ||| «Жадный» путь может увести в бедный угол поля. Например, справа 9, снизу 1, но за единицей стоят 90 и 90. Динамика учитывает **все** пути, а не только ближайший шаг. :::

## 3. Как сделать в Excel

Поле в файле лежит в A1:J10 (для 10×10). Таблицу сумм строим **под полем**, через одну пустую строку — начиная с A12.

:::steps Таблица максимумов
1. **A12** (старт): `=A1`.
2. **B12** (первая строка, только слева): `=A12+B1`. Протяни вправо до J12.
3. **A13** (первый столбец, только сверху): `=A12+A2`. Протяни вниз до A21.
4. **B13** (все остальные): `=МАКС(B12;A13)+B2`. Протяни вправо до J13, потом всю строку B13:J13 вниз до 21-й.
5. Ответ-максимум — в правой нижней клетке: **J21**.
:::

Формулы работают, потому что ссылки **относительные**: при копировании `B12` (сосед сверху), `A13` (сосед слева) и `B2` (своя монета) сдвигаются вместе с клеткой.

Таблицу минимумов строим так же ещё ниже (с A23), заменив **МАКС** на **МИН**. Ответ: `=J21&" "&J32` — оба числа через пробел.

:::warn Частая ошибка
Таблицу сумм нельзя строить **на месте** поля: формулы должны ссылаться на исходные монеты. И проверь, что смещение одинаковое во всех формулах: если поле начинается в строке 1, а таблица — в 12, то «своя монета» для B13 — это B2 (13 − 11 = 2).
:::

## 4. Стены

В некоторых задачах между клетками есть **стены** — толстые линии, через которые ходить нельзя. Тогда у клетки остаётся **один** сосед, из которого можно прийти, или ни одного кроме сверху/слева.

![Стена под B1: в B2 можно прийти только слева, без МАКС](images/xl-robot-walls.svg)

Как решать:

1. Протяни общую формулу `=МАКС(сверху;слева)+монета` на всё поле, как обычно.
2. Найди глазами клетки, у которых **стена сверху или слева**.
3. В каждой такой клетке перепиши формулу вручную: оставь только доступного соседа. Например, стена сверху — `=A13+B2` (только слева) вместо `=МАКС(B12;A13)+B2`.
4. Сделай то же в таблице минимумов.

:::warn Частая ошибка
Самое опасное место — стены в первой строке и первом столбце, и стены «через одну». Обходи поле по порядку: строка за строкой, слева направо, и отмечай на бумаге клетки со стенами.
:::

:::quiz
Над клеткой D5 — стена, слева стены нет. Какая формула верна для таблицы максимумов, если таблица начинается в строке 12 (смещение 11)?
- [ ] `=МАКС(D15;C16)+D5`
- [x] `=C16+D5`
- [ ] `=D15+D5`
- [ ] `=МАКС(D15;C16)`
---
Клетка D5 в таблице — это D16. Сосед сверху (D15) недоступен из-за стены, остаётся сосед слева C16. Плюс своя монета D5.
:::

## 5. Вариации задания

- **Робот ходит вправо и вверх** (из левого нижнего угла в правый верхний) — то же самое, но «соседи» — снизу и слева, таблицу заполняем снизу вверх.
- **Нельзя заходить в клетки с определёнными числами** — такие клетки считаем недоступными (например, ставим им очень маленькую сумму для максимума и очень большую — для минимума).

## 6. Шпаргалка урока

:::cheat
- Лучшая сумма до клетки = монета + МАКС(сверху; слева). Для минимума — МИН.
- Старт: `=A1`. Первая строка: только слева. Первый столбец: только сверху.
- Внутри: `=МАКС(B12;A13)+B2`, протянуть на всё поле. Ответ — правая нижняя клетка.
- Стены: после протягивания исправить формулы в клетках со стеной сверху/слева — оставить одного соседа.
- Ответ: максимум, пробел, минимум.
:::
