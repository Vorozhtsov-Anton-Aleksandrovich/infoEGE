# Урок 10. Задание 22: параллельные процессы

:::note Зачем это нужно
**Задание 22** ЕГЭ: таблица процессов — у каждого время выполнения и список процессов, которые должны закончиться раньше. Нужно найти, за какое минимальное время выполнится всё, если независимые процессы идут параллельно. В Excel это **один вспомогательный столбец** «время окончания».
:::

## 1. Условие

> В файле содержится информация о совокупности N вычислительных процессов. Процесс B зависит от процесса A, если для выполнения B нужны результаты A. В таблице: ID процесса, время выполнения (мс) и ID процессов, от которых он зависит (через «;», или 0, если независимый). Определите минимальное время, через которое завершится выполнение всей совокупности процессов, если независимые процессы выполняются параллельно.

| ID | Время, мс | Зависит от |
|---|---|---|
| 1 | 4 | 0 |
| 2 | 3 | 0 |
| 3 | 2 | 1 |
| 4 | 5 | 1;2 |
| 5 | 3 | 3;4 |

## 2. Идея: процесс начинается, когда закончились все «предки»

Процессы 1 и 2 ни от кого не зависят — они стартуют сразу, в момент 0, и идут **одновременно**. Процесс 4 ждёт и 1, и 2 — значит, начнётся, когда закончится **последний** из них.

**Время окончания процесса = его время + МАКС(времена окончания всех процессов, от которых он зависит)**

Если процесс независимый — время окончания равно его собственному времени.

![Диаграмма: процесс 5 заканчивается в 12 мс — это ответ](images/xl-gantt.svg)

:::steps Считаем руками для таблицы выше
1. Процесс 1: независимый → окончание **4**.
2. Процесс 2: независимый → **3**.
3. Процесс 3: ждёт 1 (4) → 4 + 2 = **6**.
4. Процесс 4: ждёт 1 (4) и 2 (3) → МАКС = 4 → 4 + 5 = **9**.
5. Процесс 5: ждёт 3 (6) и 4 (9) → МАКС = 9 → 9 + 3 = **12**.
6. Все процессы закончатся, когда закончится последний: МАКС(4; 3; 6; 9; 12) = **12 мс**.
:::

:::try Почему ответ — не сумма всех времён (4 + 3 + 2 + 5 + 3 = 17)? ||| Потому что независимые процессы идут **одновременно**: пока выполняется процесс 1, параллельно выполняется процесс 2. Сумма была бы ответом, если бы процессы шли строго друг за другом. :::

## 3. Как сделать в Excel

Таблица в файле: A — ID, B — время, C — зависимости. Процесс с ID k стоит в строке **k + 1** (в строке 1 заголовок).

:::steps Столбец D «Окончание»
1. В D1 — заголовок «Окончание».
2. Для **независимого** процесса (в C стоит 0): `=B2` — только собственное время.
3. Для **зависимого** — смотрим в столбец C и пишем ссылки на строки зависимостей. У процесса 4 (строка 5) зависимости «1;2» → это строки 2 и 3: `=B5+МАКС(D2;D3)`.
4. Идём по таблице **сверху вниз** — зависимости всегда раньше по списку, поэтому их окончание уже посчитано.
5. Ответ: `=МАКС(D2:D6)` — когда закончится последний процесс.
:::

![Таблица процессов со столбцом «Окончание»: =B5+МАКС(D2;D3)](images/xl-task22-table.svg)

Формулу в каждой строке приходится писать вручную (зависимости у всех разные), но это быстро: 20–30 строк за 5 минут. Удобно щёлкать по ячейкам мышью, пока пишешь формулу.

:::warn Частые ошибки
- Перепутать ID и номер строки: процесс 4 — это строка **5**.
- Забыть один из процессов в МАКС, если зависимостей три и больше.
- Сложить окончания зависимостей вместо того, чтобы взять максимум. Процесс ждёт **последнего**, а не всех по очереди.
- Взять в ответ окончание **последнего по списку** процесса, а не МАКС по всему столбцу. Последний в списке не обязательно заканчивается последним.
:::

## 4. Вариации вопроса

| Вопрос | Ответ формулой |
|---|---|
| минимальное время выполнения всех процессов | `=МАКС(D2:D31)` |
| сколько процессов завершится к моменту T | `=СЧЁТЕСЛИ(D2:D31;"<="&T)` |
| когда завершится процесс k | значение в D(k+1) |
| когда **начнётся** процесс k | D(k+1) − B(k+1) |
| сколько процессов выполняется в момент T | процесс идёт, если начало < T ≤ окончание: вспомогательный столбец и СЧЁТЕСЛИМН |

:::quiz
У процесса 6 время 4 мс, он зависит от процессов 2 и 5. Процесс 2 заканчивается в момент 3, процесс 5 — в момент 12. Когда закончится процесс 6?
- [ ] 19
- [x] 16
- [ ] 7
- [ ] 12
---
Процесс 6 ждёт последнего из «предков»: МАКС(3; 12) = 12. Потом выполняется 4 мс: 12 + 4 = **16**.
:::

## 5. Шпаргалка урока

:::cheat
- Окончание = своё время + МАКС(окончания зависимостей). Независимый процесс: окончание = своё время.
- Процесс с ID k — в строке k + 1.
- Формулы — сверху вниз, ссылки на столбец D строк-зависимостей: `=B5+МАКС(D2;D3)`.
- Всё закончится в момент `МАКС(D:D)`, а не в момент окончания последнего по списку.
- «Сколько завершится к T»: `=СЧЁТЕСЛИ(D2:D31;"<="&T)`.
:::
