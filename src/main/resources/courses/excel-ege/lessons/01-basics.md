# Урок 1. Знакомство с Excel

:::note Зачем это нужно
На ЕГЭ по информатике есть задания, которые быстрее всего решаются в электронной таблице: **3** (базы данных), **9** (анализ строк таблицы), **18** (робот на поле), **22** (параллельные процессы). На станции КЕГЭ стоит Microsoft Excel или LibreOffice Calc — курс учит работать в обоих. Сегодня — самое начало: как устроен лист, что такое ячейка и как быстро двигаться по большим таблицам.
:::

## 1. Что такое электронная таблица

**Электронная таблица** — это программа, в которой данные лежат в клеточках, как в тетради по математике. Но в отличие от тетради таблица умеет **сама считать**: напишешь формулу один раз — она пересчитается при любом изменении данных.

Посмотри на окно Excel. Главные части подписаны:

![Окно Excel: лента, поле имени, строка формул, ячейки, ярлыки листов](images/xl-interface.svg)

- **Лента** вверху — вкладки с кнопками: «Главная», «Вставка», «Формулы», «Данные». Почти всё в курсе будет на вкладках «Главная» и «Данные».
- **Поле имени** — слева от строки формул. В нём написан адрес выбранной ячейки.
- **Строка формул** — показывает, что *на самом деле* записано в ячейке (например, формулу).
- **Лист** — сама сетка из клеточек.
- **Ярлыки листов** — внизу. В одном файле (его называют **книгой**) может быть несколько листов, как страницы в тетради.

## 2. Строки, столбцы, ячейки

- **Столбцы** обозначены **буквами**: A, B, C, …, Z, потом AA, AB, … Буквы стоят над листом.
- **Строки** обозначены **числами**: 1, 2, 3, … Числа стоят слева.
- **Ячейка** — клеточка на пересечении столбца и строки.

Каждая ячейка имеет **адрес**: сначала буква столбца, потом номер строки. Ячейка в столбце B и строке 3 — это **B3**.

![Ячейка B3 — пересечение столбца B и строки 3](images/xl-address.svg)

Одна ячейка всегда **активная** — она обведена зелёной рамкой. С ней ты сейчас работаешь: если начать печатать, текст появится в ней. Её адрес виден в поле имени.

:::try Какой адрес у ячейки в столбце D и строке 12? ||| **D12** — сначала буква столбца, потом номер строки. Запись «12D» Excel не поймёт. :::

:::warn Частая ошибка
Адреса пишутся **латинскими** буквами. Русские «А», «В», «С» выглядят так же, но для Excel это другие символы: `=А1` с русской «А» даст ошибку.
:::

## 3. Ввод данных

Щёлкни по ячейке и начни печатать. Чтобы закончить ввод, нажми **Enter** (курсор уйдёт вниз) или **Tab** (вправо). **Esc** отменяет ввод.

Excel сам понимает, что ты ввёл:

![Текст прижимается влево, числа и даты — вправо](images/xl-data-types.svg)

- **число** прижимается к **правому** краю ячейки;
- **текст** — к **левому**;
- **дата** — это тоже число (Excel хранит её как номер дня), поэтому она справа.

Это удобная проверка: если число вдруг прижалось влево, значит, Excel считает его текстом (например, там лишний пробел или точка вместо запятой) и **считать его не будет**.

:::note Запятая или точка
В русской версии Excel дробную часть отделяют **запятой**: 2,5. Если написать 2.5, Excel может решить, что это дата или текст. В LibreOffice с русскими настройками — так же.
:::

Чтобы **исправить** содержимое ячейки, выдели её и нажми **F2** (или дважды щёлкни) — появится курсор внутри ячейки. Если просто начать печатать, старое содержимое **заменится** целиком.

## 4. Выделение

- **Одна ячейка** — щелчок.
- **Диапазон** (прямоугольник ячеек) — протяни мышью от одного угла до другого. Диапазон записывают через двоеточие: **A1:C5** — от A1 до C5.

![Диапазон A1:C5](images/xl-range.svg)

- **Весь столбец** — щелчок по букве над ним. **Вся строка** — по номеру слева.
- **Несколько отдельных диапазонов** — выделяй, удерживая **Ctrl**.
- **Весь лист** — Ctrl + A или уголок слева от буквы A.

:::try Сколько ячеек в диапазоне A1:C5? ||| 3 столбца (A, B, C) × 5 строк = **15** ячеек. :::

Когда выделено несколько чисел, внизу окна, в **строке состояния**, Excel сразу показывает их **сумму**, **среднее** и **количество**. Формулы для этого не нужны — очень полезно для быстрой проверки.

![СКРИНШОТ: строка состояния Excel внизу окна — «Среднее», «Количество», «Сумма» для выделенного столбца](images/todo-status-bar.png)

## 5. Автозаполнение

В правом нижнем углу активной ячейки есть маленький квадратик — **маркер заполнения**. Если потянуть за него, Excel продолжит то, что ты начал.

![Ввели 1 и 2, выделили, потянули за маркер — получили 1, 2, 3, 4, 5, 6](images/xl-autofill.svg)

:::steps Как пронумеровать строки от 1 до 100
1. В A1 впиши **1**, в A2 — **2**.
2. Выдели обе ячейки (A1:A2).
3. Наведи мышь на маркер в правом нижнем углу — курсор станет тонким крестиком **+**.
4. Потяни вниз до A100 и отпусти — Excel продолжит ряд: 3, 4, 5, …
:::

**Двойной щелчок по маркеру** протягивает вниз сразу до конца соседнего заполненного столбца. Это главный приём курса: формулу на 5000 строк не нужно тянуть мышью.

Автозаполнение понимает и дни недели, месяцы, «Задача 1, Задача 2…».

## 6. Быстрое перемещение: горячие клавиши

В заданиях ЕГЭ таблицы бывают на тысячи строк. Прокручивать колёсиком — долго. Запомни эти клавиши:

| Клавиши | Что делают |
|---|---|
| **Ctrl + ↓** (↑ → ←) | прыжок до конца блока данных в эту сторону |
| **Ctrl + Shift + ↓** | то же, но ещё и **выделяет** всё по пути |
| **Ctrl + Home** | в ячейку A1 |
| **Ctrl + End** | в последнюю заполненную ячейку листа |
| **F2** | редактировать ячейку |
| **Ctrl + Z** | отменить последнее действие |
| **Ctrl + F** | найти |

Ещё один быстрый способ: щёлкни в **поле имени**, впиши адрес (например, `F137`) и нажми Enter — Excel перенесёт тебя прямо туда.

:::try Как за две секунды узнать, сколько строк заполнено в столбце A? ||| Встань в A1 и нажми **Ctrl + ↓**: курсор прыгнет на последнюю заполненную ячейку, её номер строки виден слева и в поле имени. :::

## 7. Excel и LibreOffice Calc

На станции ЕГЭ может стоять любая из двух программ. Они очень похожи:

| | Excel | LibreOffice Calc |
|---|---|---|
| Адреса, формулы, функции | одинаково | одинаково (имена функций те же) |
| Разделитель аргументов | `;` | `;` |
| Меню | лента с вкладками | классическое меню «Файл, Правка, Вид, …, Данные» |
| Сортировка и фильтр | **Данные → Сортировка / Фильтр** | **Данные → Сортировать… / Автофильтр** |
| Горячие клавиши из таблицы выше | работают | работают |

Когда будут отличия, в уроке будет пометка **«В LibreOffice: …»**.

![СКРИНШОТ: окно LibreOffice Calc с открытым меню «Данные»](images/todo-libreoffice-window.png)

## 8. Открыть файл задания и не испортить его

1. Скачай файл задачи (кнопка «⬇ Скачать файл» под условием).
2. Открой его двойным щелчком. Если Excel пишет «Защищённый просмотр» — нажми **«Разрешить редактирование»**.
3. Работай: вспомогательные формулы можно писать в свободных столбцах справа от данных.
4. Если что-то сломал — **Ctrl + Z** столько раз, сколько нужно. Или просто скачай файл заново.

![СКРИНШОТ: жёлтая полоса «Защищённый просмотр» и кнопка «Разрешить редактирование»](images/todo-protected-view.png)

:::warn Частая ошибка
Не сортируй и не удаляй строки в исходных данных, пока не уверен, — легко перемешать таблицу. На ЕГЭ файл не жалко: всегда можно открыть исходник заново.
:::

## 9. Шпаргалка урока

:::cheat
- Столбцы — буквы, строки — числа. Адрес ячейки: **B3** (буква, потом число, латиница).
- Диапазон: **A1:C5**. Весь столбец — щелчок по букве.
- Числа прижимаются вправо, текст — влево. Дробная часть — через **запятую**.
- **F2** — редактировать, **Esc** — отменить ввод, **Ctrl + Z** — отменить действие.
- **Ctrl + ↓** — к концу данных, **Ctrl + Shift + ↓** — выделить до конца, **Ctrl + Home** — в A1.
- Поле имени: впиши адрес и нажми Enter, чтобы перейти к ячейке.
- Маркер заполнения: потянуть — продолжить ряд; **двойной щелчок** — до конца данных.
- Строка состояния показывает сумму, среднее и количество выделенного.
:::
