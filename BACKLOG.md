# BACKLOG

Идеи вне текущего плана. Не реализуются без отдельного решения.

## Из плана (вне текущего объёма)
- Проверка на плагиат.
- Автооценка сложности задания по статистике попыток (данные уже копятся в `attempt_answer`).
- Запуск кода учеников.
- Группы учеников.
- Публичный банк заданий.
- Платежи.
- Уведомления.

## Замечено при разработке
- Переход на Spring Boot 4.x: в плане указан Boot 3, проект собран на 3.5.6.
- Смена пароля преподавателя из интерфейса (сейчас аккаунт создаётся только из ENV при первом запуске).
- Пагинация банка заданий (сейчас список целиком, при сотнях заданий станет нужна).
- Вставка картинки в условие перетаскиванием или из буфера обмена.
- Хранилище файлов в S3-совместимом сервисе (интерфейс `FileStorage` уже есть).
- Перетаскивание заданий мышью при сборке подборки (сейчас кнопки вверх/вниз).
- Повторное назначение той же работы тому же ученику (пересдача); сейчас нужно сделать копию.
- Смена имени и логина ученика преподавателем.
- Сверить вёрстку тренажёра со скриншотами станции КЕГЭ (`docs/kege-screens/` пока нет).
- Копия несохранённых ответов в localStorage на случай закрытия вкладки без сети.
- Кнопка «На весь экран» (Fullscreen API) в тренажёре.
- Перепроверка завершённых попыток после исправления правильного ответа в задании.
