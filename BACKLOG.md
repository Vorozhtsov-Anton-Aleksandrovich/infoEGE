# BACKLOG

Идеи вне текущего плана. Не реализуются без отдельного решения.

## Из плана (вне текущего объёма)
- Проверка на плагиат.
- Автооценка сложности задания по статистике попыток (данные уже копятся в `attempt_answer`).
- Запуск кода учеников.
- Группы учеников.
- Публичный банк заданий.
- Платежи.
- Уведомления.

## Замечено при разработке
- Переход на Spring Boot 4.x: в плане указан Boot 3, проект собран на 3.5.6.
- Смена пароля преподавателя из интерфейса (сейчас аккаунт создаётся только из ENV при первом запуске).
